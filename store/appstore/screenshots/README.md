# App Store screenshots

Coloca aquí las capturas descargadas del artefacto **`ios-app-store-screenshots`** del
workflow `iOS CI` (runner macOS), una subcarpeta por clase de dispositivo:

- `iphone-6-9/` — iPhone 6.9" (obligatoria)
- `iphone-6-5/` — iPhone 6.5" (opcional)
- `ipad-13/` — iPad 13" (obligatoria si la app soporta iPad)

Las carpetas se mantienen vacías en el repo (`.gitkeep`) hasta que el CI genere el set.
Ver `../ASSETS.md` para el detalle de resoluciones y las pantallas incluidas.
