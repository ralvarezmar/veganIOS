---
title: Gluon Migration Guide from Jenkins
---

To start the migration journey note that you need a previously created application within the Gluon Portal before creating any component, to do so, check this [guide](../app-onboarding/index.md) on how to onboard your application in the Gluon Portal.

To facilitate the migration of source code repositories associated with Jenkins pipelines to Gluon components, comprehensive technical documentation has been developed to support the adaptation for different technologies.
As a prerequisite, the target app associated with the project associated with the Jenkins component to migrate must be previously created.
You can check this [application onboarding guide](../app-onboarding/index.md) on how to onboard your application in the Gluon Portal.

## Table of equivalences Jenkins-Gluon

Depending on the pipeline used in Jenkins, the specific documentation for migration that you need can be obtained from the following table of equivalences.
