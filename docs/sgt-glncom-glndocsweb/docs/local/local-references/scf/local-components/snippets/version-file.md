The `VERSION` file (with no extension) plays a crucial role in the Gluon Workflow Actions by providing a way to read and manage your project's version.
Since some technologies such as PHP, Gradle, Drupal are not yet supported natively within the Gluon platform, this file serves as an alternative method for version control.
It is essential to maintain this file accurately and keep it updated to ensure that the workflow actions can correctly interpret and utilize the version information.

The `VERSION` file should contain a single line specifying the current version of your project. This versioning system helps in tracking changes, managing releases, and ensuring consistency across different stages of development and deployment.
By adhering to a proper versioning convention, you can facilitate better collaboration and maintain a clear history of your project's evolution.

Here is an example of what the `VERSION` file might look like:

```yml
1.0.0
```
