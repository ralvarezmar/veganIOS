Gluon's Security offering can be divided into two key areas:

- Secure Software Development Lifecycle
- Security Enablers

You can find details of each of these in the following sections:
<br>

<div class="cards row-3" markdown>

- #### [S-SDLC](SSDLC/index.md)

    ---

    Everything that Gluon offers to guarantee that your applications are developed securely.

    <br>

- #### [Security Enablers](security-enablers/index.md)

    ---

    Services that support the secure execution of applications.

    <br>  

- #### [Security Gluon On Boarding](sgon.md)

    ---

    _SGOn_ uses Hashicorp Vault Community as Secret Manager.
    The microservice allows to manage secrets, creating a structure by company and application in a Vault, based on the Naming Convention defined in Gluon.

    In addition, during the Company and Application onboarding process, roles, policies and AD Groups will also be created.

    The use of the microservice is reserved for users with a valid jwt.
