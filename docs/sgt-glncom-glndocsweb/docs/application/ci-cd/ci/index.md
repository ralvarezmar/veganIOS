
# **Continuous Integration Workflows (CI)**

## **1. Introduction**

The purpose of this documentation is to have a step-by-step guide on how
the integration of applications can be orchestrated in Gluon,
so that you can build each of our available components through a
CI process.

Deployment will be done by the CD workflows.

## **2. How to use the project CI workflows?**

There are different component templates that brings you the possibility of creation
an empty workflow ready to work, you can learn more about this in the
[Onboarding documentation](../../component-management/create-component.md)

Once you have created the empty repository from a template, you will
have several workflows ready to use in this case you have to choose
your specific technology.
