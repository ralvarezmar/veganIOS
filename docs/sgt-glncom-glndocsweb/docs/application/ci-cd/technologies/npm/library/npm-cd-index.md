
# **NPM Applications Library**

## **1. Introduction**

The purpose of this documentation is to have a step-by-step guide on how
the integration of NPM applications Library can be orchestrated in Gluon,
so that you can build and upload to binary repositories (Nexus)
each of our NPM components through a CI process.

## **2. How to use?**

After using the [NPM CI Workflow](./npm-ci-library.md), you can push the
image to Nexus using the [NPM RL Workflow](./npm-rl-library.md). If you
are creating a new repository from scratch, you can learn more about this in
the [Onboarding documentation](../../../../component-management/create-component.md).
