Within the software life cycle, one of the main tools available to ensure the correct functionality and performance of a
development, as well as to reduce the number of bugs that reach production, is automatic testing. For this reason, Gluon provides
the user with a series of frameworks in which they can develop automatic tests as well as a series of tools with which they can
execute the tests and integrate them into the software life cycle.

Gluon has different frameworks in which automatic test can be developed. Frameworks can be differentiated according to the purpose
of the tests. On the one hand, three frameworks are available for Web and API testing. The first of them is TalosBdd based on python
and two others, Cilantrum and Nitro, based on Java. In addition to this, there is also a specific framework for API testing called Newman.
There is also Appium for mobile testing using Saucelabs.

In addition to the frameworks, Gluon provides two ways to execute and integrate tests within the component deployment cycle:

- [Gluon Testing Portal](portal/index.md){:target="_blank"}
- [Gluon Testing Workflows](workflows/index.md){:target="_blank"}
