It is recommended that the testing frameworks are up to date. For this, we have created this action. It checks the actual version of the component and compare it with the latest one the component should use.

If the component is using a lower version, the action will return a warning with the message and with the link to the documentation on how to update the component.
For more info: [Update Component](https://gluon.gs.corp/community/docs/latest/application/component-management/update-component/#updating-your-component)
