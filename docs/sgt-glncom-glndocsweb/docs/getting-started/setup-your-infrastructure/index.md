## How to request your infrastructure

Nowadays Gluon doesn't provide the infrastructure as a service, so you need to request it as usual in your company

In next releases Gluon will provide this capability

## What Infrastructure do I need?

- Kubernetes Cluster
- Kubernetes Namespace, to create the namespace you can follow this [**guide**](../../components/configuration/kubernetes/namespace_harbor.md)
- Registry
