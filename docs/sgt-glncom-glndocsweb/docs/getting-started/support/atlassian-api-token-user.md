---
title: Atlassian API Token User
---

Starting from December 15, 2024, Atlassian established the expiration of user API tokens for new tokens. Keep this in mind if you use Atlassian user API tokens in any script or automation with Atlassian products.
You need to review the expiration date of your user API token and plan to generate a new user API token to replace it where it is used.

???+ info
    For more information: [Manage API tokens for your Atlassian account](https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/)
