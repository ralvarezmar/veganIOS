## Atlassian Intelligence

Atlassian Intelligence (AI) is activated in the corporate sites (instances) for Jira and Confluence.<br>
The way to use it, the features included and some best practices are available in the following [Atlassian AI documentation](https://support.atlassian.com/organization-administration/docs/get-started-with-atlassian-intelligence-guide/)

## Atlassian Rovo

Atlassian Rovo is an integrated tool in Jira, Confluence etc, that provides AI-powered apps to help find, learn, and act on information dispersed across Atlassian apps (Jira and Confluence) and third-party apps more quickly and efficiently.
Rovo that can help to solve some of the most common workplace challenges, including:<br>
✔ Locating information.<br>
✔ Contextual knowledge discovery<br>
✔ Making decisions<br>
✔ Repetitive, time-consuming tasks<br>

More information about Rovo <br>
[What is Rovo](https://support.atlassian.com/rovo/docs/what-is-rovo/)<br>

Additionally it is available a [free Atlassian quick start course about Rovo](https://community.atlassian.com/learning/course/get-started-quickly-with-rovo)

### Rovo AI main powered apps

- **Rovo Search and Chat**: Quickly find information and gain knowledge.<br>
- **Rovo Agents**: Execute tasks efficiently.<br>
- **Rovo Studio**: Build AI agents, automation and apps.<br>

More detailed information about all the AI powered apps usage is available in the following
[Atlassian Rovo Usage Documentation](https://support.atlassian.com/rovo/docs/using-rovo/)

### Rovo activation on a corporate Santander Atlassian site

???+ success "Rovo availability and activation"
    **Atlassian made Rovo available in July 2025, but it was not activated by default on Santander Production sites.**<br>
    Atlassian will activate Rovo on all sites where not activated manually as a mandatory measure, on a date to be determined. The date will be communicated in due course.<br>
    Until then, **Atlassian provides a way for Atlassian Santander organization administrators to manually activate Rovo on sites on demand.**
???+ tip "Check if Rovo is enabled in the Atlassian site App (Jira/Confluence)"
    You can quickly check if Rovo is already active on your site by looking for the "Rovo chat" button on the right side of the top bar as indicated in [Atlassian Rovo Chat Doc](https://support.atlassian.com/rovo/docs/accessing-chat/)
???+ danger "Rovo temporary manual activation in sites on-demand"
    - **Atlassian Local Site Admins** have to request the manual activation of Rovo in their Self-Managed site through a [Gluon Support ITSM](https://gluon.gs.corp/community/docs/latest/getting-started/support/#create-a-new-support-inc)<br>
    ??? quote "Time required to schedule the activation of Rovo on a site"
        The activation of Rovo in the requested site will be scheduled with a change between 24 and 72 hours after the request is processed.<br>
        If you would like the Rovo activation to occur at a specific date and time after this period, please indicate it in the description of the ITSM request.<br>
    **Local Site Admin Validation:** The Atlassian local administrator could confirm Rovo activation following the [Rovo activation checks](https://www.atlassian.com/software/rovo/guides/admin-guide/rovo-activation#confirm-activation)

### Rovo usage limitations

???+ warning "Information about Rovo quota usage limitations"
    Atlassian Rovo usage is included in an Atlassian site once activated and it is associated to AI (Atlassian Intelligence).<br>
    **During the first months (to be determined)** all the Rovo features will be available for users with license without real usage limits applied.<br>
    ???+ danger "Upcoming Rovo usage limits"
        Please note that Atlassian communicated that after the initial period since activation will apply [Rovo quota and limits](https://support.atlassian.com/rovo/docs/rovo-usage-limits/) in Santander Atlassian Organization.<br>
        - **At that point there will be necessary to review Rovo usage and set some monthly Rovo usage limits per user to avoid exceed the available Rovo quota in the Santander corporate instance and any additional charges.**<br><br>
    ???+ tip "Recommendation"
        **Use Rovo features while keeping in mind that you should avoid reliance on them for critical processes or frequent daily work tasks executed undetermined times until the usage limits will be clearly defined.**<br>
        This should prevent potential future work disruptions when monthly user Rovo usage limits are activated.<br><br>

    Further details will be communicated as appropriate through Gluon channels when Rovo usage limit per user will be determined.

### Rovo deactivation on a corporate Atlassian site

Note that in case any Self-Managed Site decide to disable Rovo for any reason in a corporate site app (Jira,Confluence) **it will be necessary to disable the Atlassian Intelligence (AI) in the site**.<br>
The (Rovo + AI) deactivation could be requested by an Atlassian Site Local Admin through a [Gluon Support ITSM](https://gluon.gs.corp/community/docs/latest/getting-started/support/#create-a-new-support-inc)
