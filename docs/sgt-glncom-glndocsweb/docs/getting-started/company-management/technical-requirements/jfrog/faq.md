## Do you apply any cleanup policy?

- Yes, we apply cleanup policies for regular packages and remote packages. For more information, please check [here](./introduction.md).

## Is there any nomenclature regarding repositories?

- Yes, you can find information about repository nomenclature [here](./introduction.md).

## What types of repository technologies are allowed in JFrog Artifactory?

The following repository technologies are supported by JFrog Artifactory:

- **maven**
- **debian**
- **npm**
- **nuget**
- **yum**
- **cargo**
- **helm**
- **conan**
- **gradle**
- **gems**
- **cocoapods**
- **go**
- **terraform**
- **pypi**
- **huggingfaceml**
- **docker**
- **generic**
- **oci**
- **helmoci**
