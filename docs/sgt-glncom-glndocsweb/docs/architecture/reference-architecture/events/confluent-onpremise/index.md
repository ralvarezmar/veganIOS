# Confluent Technical Reference Architecture

Confluent Platform is an open-source event streaming platform based on Kafka, created by the original developers of Kafka at LinkedIn. It enables the creation of real-time data channels and streaming applications by integrating data
from various sources into a single central event streaming platform.

The platform includes several key components that facilitate the creation of end-to-end pipelines, providing comprehensive enterprise solutions. These components include Kafka Streams & KSQL, Kafka Connectors, Schema Registry, Rest Proxy, and Replicator.

Additionally, Confluent Platform offers specific components for monitoring the architecture and implementing security at all levels, from individual components (connectors, topics, streams, etc.) to connectivity and data.
