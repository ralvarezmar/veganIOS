# Vocabulary

| Term           | Description                                                                                                                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MFE            | Acronym for Micro Front End. @see _Microfront_                                                                                                                                          |
| Micro Frontend | @see _Microfront_                                                                                                                                                                       |
| Microfront     | Atomic functionality exposed as a reusable, scalable and decoupled UI piece capable of being integrated into a larger application (called Shell) in an framework-agnostic way.          |
| Shell          | Web or Mobile application that will display and orchestrate the Microfronts in a coherence way for the final user.                                                                      |
| Shell Lite     | Web application that will display a single MFE in a Mobile (or Contact Center/Digital Branch) scenarios. It will act as a pipe between the Shell and the MFE                            |
| TRA            | Acronym for Technical Reference Architecture.                                                                                                                                           |
| Web Components | Suite of different technologies allowing you to create reusable custom elements — with their functionality encapsulated away from the rest of your code — and use them in your web apps |
