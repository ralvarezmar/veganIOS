# **Models**

<div class="cards row-auto" markdown>

- ##### Mainframe Synchronized model

    ---

    Mainframe Synchronization is aimed to deploy nexus packages, coming from a given frozen Gipih, in the client environments (PRE or PRO) once mainframe client is not longer available (this model is also called 'on the fly' packages deployment)

    <br>

    ---

    [Mainframe Synchronized model](./gravity-partenon-synchro-model/index.md){ .md-button }

- ##### Model2 (Goberned by Mainframe)

    ---

    Using librarian as configuration control tool, objects are loaded into a given branch
    over a github repository and therefore gravity deployment may be triggered using the
    appropriate GLUON workflows.

    <br>

    ---

    [Model2](./gravity-partenon-model2/index.md){ .md-button }

- ##### Native Model

    ---

    Development effort is done directly in github.com so users can fulfill SW lifecycle in gravity using GLUON workflows.
