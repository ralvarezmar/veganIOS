# First Steps

To use the NgDarwin library, you have two options depending on your needs:

- **Darwin Front CLI**: It is an archetype generator tool. It gives you the possibility to generate a Darwin SPA archetype with all the components configured, and other types of artifacts in different versions.
This is the recommended option if the project is going to be started from scratch. You can learn more about how it works [here](../../cli/index.md).
- **Custom or Manual**: This is the recommended option for existing Angular projects that want to use the NgDarwin libraries. For this option it is best to go to the information of each module that is part of NgDarwin at the following [link](https://automatic-doodle-rew2y31.pages.github.io){:target="_blank"}
