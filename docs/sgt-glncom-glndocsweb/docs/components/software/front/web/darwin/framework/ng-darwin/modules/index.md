- ### @ng-darwin/config

    ---

    This module solves the need to configure `@ng-darwin/logger` and `@ng-darwin/logger` modules with properties that may vary by environment.
    It offers as well the possibility a Web application can take advantage of having their own necessary custom configuration properties and variables by environment.

    <br>

    ---

    [:material-arrow-right: @ng-darwin/config](config/index.md){ .md-button }

- ### @ng-darwin/security

    ---

    Most applications will need to use the utilities offered by this module to manage the security of the request, inject the BKS token and manage its lifecycle.

    <br>

    ---

    [:material-arrow-right: @ng-darwin/security](https://automatic-doodle-rew2y31.pages.github.io/modules/_ng-darwin_security.html){ .md-button }

- ### @ng-darwin/logger

    ---

    One of the requirements of Front applications is to visualize the errors or the custom activity traces that have occurred with tools like Kibana for example. To fulfill this requirement, this module has been developed.

    <br>

    ---

    [:material-arrow-right: @ng-darwin/logger](logger/index.md){ .md-button }
