# Breaking Changes

To migrate **ng-darwin** libraries to **18.x.x** version, the following **breaking changes** must be considered:

## Angular framework upgrading

- This new release does not involve any _breaking changes_ compare to the previous major release of `@ng-darwin` 16.x.x.
The great advantage it has is to offer compatibility with a newer version of the Angular framework, and that application developers can take advantage of it.
The different libraries of `@ng-darwin` **18.x.x** only work with **Angular 18**, so it will be necessary for applications to migrate to this version of Angular.
You can help yourself with the [Angular Update Guide](https://update.angular.io/){:target="_blank"} provided by the Angular team itself.
