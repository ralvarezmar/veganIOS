# Logger Module

One of the requirements of Front applications is to visualize the errors or the custom activity traces that have occurred with tools like [Kibana](https://kibanaedhes.santander.corp/login?next=%2Fapp%2Fkibana) for example.
To fulfill this requirement, the `Logger` module has been developed.

For more information about `Logger` module follow this [documentation](https://automatic-doodle-rew2y31.pages.github.io/modules/_ng-darwin_logger.html){:target="_blank"}.

Extra features this module offers:

- [Tealium Integration](./tealium-integration.md)
