# `MicrofrontModule`

## Description

Main module of `@ng-darwin-wmf/microfront`, required for some functionalities.

``` ts
class MicrofrontModule {
}
```

## Services

| Name | Description |
|---|---|
| [MountPathService](./mountpathservice.md) | Service used to retrieve the mount path configured |

## Pipes

| Name | Description |
|---|---|
| [PrefixAssetPipe](./prefixassetpipe.md) | Adds a prefix to the urls to assets based on the `technicalGrouping` |
| [MountPathPipe](./mountpathpipe.md) | Adds a prefix to the urls of links based on the `mountPath` configured |
