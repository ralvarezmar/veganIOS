# CIP Authentication

CIP (Customer Identity Platform) authentication is a security system that provides an OAuth authorization flow, including obtaining, storing, rotating, and injecting tokens.
This system also handles user login through the authorization server and offers logout features.

For more details on how to implement and configure CIP authentication in your application, refer to the functional documentation for [Angular](use-it-in-angular.md) and [React](use-it-in-react.md).
