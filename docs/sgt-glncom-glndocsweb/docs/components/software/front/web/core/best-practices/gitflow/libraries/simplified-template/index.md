# Simplified Template

More practical model with fewer steps to be executed.

It is closer to a ***Continuous Delivery*** model.

With this model, it is possible to execute faster value deliveries without the need to accumulate changes. Each new version has few or only one change, whether it's a new feature or a bug fix.

This model makes sense for library projects that fall into the following scenarios:

- Few active developers
- Fast and objective deliveries
