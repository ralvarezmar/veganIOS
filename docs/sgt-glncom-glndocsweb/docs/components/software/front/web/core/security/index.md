# @santander/security

## Functional overview

The Security Context Manager (SCM) is a front-end javascript library designed to help Single Page Applications (SPAs) manage security tokens when consuming backend APIs protected by OAuth 2.0 or CIP Login.

It aims to do this in the most transparent, secure way possible, leaving the
developer to focus on implementing the business aspects of their application.
