# Comparative between Angular 10 e 11

| Angular 10                | Angular 11                  |
| ------------------------- | --------------------------- |
| ***TypeScript***: 3.9     | ***TypeScript*** 4.0        |
| ***RxJs***: ~6.5.5        | ***RxJs***: ~6.6.0          |
| ***jasmine***: ~3.5.0     | ***jasmine***: ~3.6.0       |
| ***karma***: ~5.0.0       | ***Karma***: 5.1.0          |
| ***node***: 10.13.x/12.11 | ***node***: 10.13.x/12.11.x |
