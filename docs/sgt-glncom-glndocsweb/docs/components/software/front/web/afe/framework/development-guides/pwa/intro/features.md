# Features of a ***PWA***

The main features of a PWA are:

- **Progressive:** works for all users, regardless of the browser chosen, as it is built based on the principles of progressive improvement;
- **Responsive:** can be developed to adapt to any screen format;
- **Offline:** From the moment the ***PWA*** is downloaded to a device, part of the content can be available to the user regardless of internet connection;
- **Similar to native apps:** Aesthetics and usability similar to native apps;
- **Updated:** as a ***PWA*** makes use of ***Service Workers***, it is automatically updated, without depending on user action;
- **Secure:** uses ***HTTPS*** protocol;
- **Discoverable:** is indexed by search engines;
- **Installable:** Can be downloaded and installed on devices from the browser, without any process involving app stores;

Therefore, the most conducive situations to adopt a ***PWA*** are:

- When an app needs to be able to reach a large number of users. Since PWAs are first and foremost web pages, they can be found through search engine searches, require fewer steps to download and take up little memory on devices;
- Being indexed by search engines is important;
- Cross-platform compatibility is essential;
- Multiple updates are needed in a short period of time;
- It is desirable that the ***download*** of the ***app*** has few steps, avoiding discouraging users.
