# CSP Policy Configuration

## Contextualization

When an application needs to configure the ***Content-Security-Policy*** header, any request for a resource or ***asset*** that is not specified in it will cause a ***CSP (Content Security Policy)***.

## Architecture Guidelines

Configure the [Content Security Policy](https://confluence.santanderbr.corp/display/AFE/Content+Security+Policy) to receive or make any requests for resources allocated in the ***santanderbr.pre.corp***.
As described in the documentation on [Content Security Policy (CSP) Settings](../../../development-guides/deployment/headers/csp.md).
