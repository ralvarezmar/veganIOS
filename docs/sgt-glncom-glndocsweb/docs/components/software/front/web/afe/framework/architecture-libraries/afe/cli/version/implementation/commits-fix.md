# Fix commits

If you have made one or more commits that did not follow the specified nomenclature and you want those commits to have an effect on updating the ***CHANGELOG.md*** and you can change the commit history to meet the need

## Latest commit

If it's the last commit that needs to be fixed in the message, you can change it using the ['git amend'](https://www.atlassian.com/git/tutorials/rewriting-history#git-commit--amend) command.

## Old Commits and Multiple Commits

If they are older commits or there is a need to group commits to form a single commit containing the desired nomenclature, you can use the ['git rebase -i'](https://www.atlassian.com/git/tutorials/rewriting-history#git-rebase-i) command

> The change can also be made from ***HEAD*** of ***git***.
