# @afe/file-transfer version

If your project uses the ***1.x.x*** version of the ***@afe/file-transfer*** package, it is possible that it will have conflicts due to multiple instances of ***HttpClient***.

## Solution

 To solve the problem, simply update the part to version ***2.0.0*** or higher, using the command:

```bash
npm i @afe/file-transfer@^2
```
