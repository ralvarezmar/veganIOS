# Modules

The library modules cover some of the most common needs in communicating with the Services HUB. For implementation of each interceptor, see the documentation for each module below:

| Interceptor | Objective |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| [SSO Interceptor](./sso-interceptor.md) | Import and configure the interceptor for SSO calls |
| [HubConnector Interceptor](./hub-connector-interceptor.md) | Communicate with the Services Hub, managing the exchange of tokens between requests |
| [Tracing Interceptor](./tracing-interceptor.md) | Send Objects to the Tracing Endpoint |
| [Retry Interceptor](./retry-interceptor.md) | Retry calls that returned a certain error |
