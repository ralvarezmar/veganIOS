# How to troubleshoot "***401 not authorized***"

The HTTP client error status code ***401 Unauthorized*** indicates that the request was not applied because it does not have valid authentication credentials for the target resource.

Below is a list of the scenarios mapped to the ***401 Unauthorized*** issue during HTTP calls in your application:

**Mapped scenarios:**

- [@http-interceptors configuration](./http-interceptors.md)
- [Multiple modules importing HttpClient](./multiple-instances-httpclient.md)
- [Module Import Order](./import-order.md)
- [@afe/file-transfer version](./file-transfer.md)
- [Configuration of headers in CDG](./headers-configuration.md)
