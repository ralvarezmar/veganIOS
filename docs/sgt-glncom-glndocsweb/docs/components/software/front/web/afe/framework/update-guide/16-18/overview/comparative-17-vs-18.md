# Comparison between Angular 17 and 18

The main differences between the versions are:

| ***Angular 17*** | ***Angular 18*** |
| --------- | ---------- |
| Supported NodeJS versions: **18.13** and **20.9**. | Supported NodeJS versions: **18.19**, **20.11**, and **22.0**. |
| Support for TypeScript **5.2**. | Support for TypeScript **5.4**. |
