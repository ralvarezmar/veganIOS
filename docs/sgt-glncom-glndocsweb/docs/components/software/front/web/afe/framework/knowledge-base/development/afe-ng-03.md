# AFE-NG01-03 Initial exceeded maximum budget

During the execution of the 'npm run build' command, the following warning may be triggered:

```bash
Error: initial exceeded maximum budget. Budget 2.00 MB was not met by 158.06 kB with a total of 2.15 MB.
```

## Contextualization

The **"Initial exceeded maximum budget"** error occurs due to the size of the files, in ***mega bytes***, generated during the ***build*** process being above what was defined in the Angular configuration file.

## Architecture Guidelines

The ***maximumError*** option is responsible for triggering an error message when the size limit of a bundle is exceeded. **Do not remove this property under any circumstances**, as it allows us to control the size of the application.

Similarly, it is necessary to review the complexity and implementations of the project, so that the MB size of the bundle can be reduced to a suitable size.

## Solution

Increase the maximum size of the warnings generated by changing the ***maximumError*** property in the ***angular.json***:

```diff
{
  "projects": {
    "<SEU_PROJETO_ATUAL>": {
      "architect": {
        "build": {
          "configurations": {
            "production": {
              "budgets": [
                {
-                  "maximumError": "2mb",
+                  "maximumError": "3mb", // maximum size of the warnings
                }
              ],
            }
          }
        },
      }
    },
}
```
