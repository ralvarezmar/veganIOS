# Release of the resource for consumption of the application

## Contextualization

It may be that the ***app-key*** of the application that is trying to consume the resource does not have permission to perform this action, causing the ***Application key is not allowed to call this resource method***.

## Solution

To resolve the issue, it is necessary for the governance of the endpoint to release the URLs to the development environment, the approval environment, and the production environment. Such requests are made by filling out the [form for consumption of ***APIs***](https://confluence.santanderbr.corp/pages/viewpage.action?pageId=282044791)
