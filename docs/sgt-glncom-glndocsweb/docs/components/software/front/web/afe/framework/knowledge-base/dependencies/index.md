# Libraries and Dependencies

This session aims to provide guidance and resolution of common problems regarding libraries and dependencies used in the project.

## 🎯 Overview

Errors related to libraries and community dependencies can be related to:

- Implementation or incorrect configuration of the library;
- **Library version incompatible with Angular version**;
- Library not supported by the architectural model of the project;

## 📋 Initial Checklist

Before proceeding to the mapped scenarios that we have documented, follow the checklist to do a recap of the procedure required for using external libraries and dependencies:

- Go to the documentation for the library or dependency and **follow the installation and configuration guide**;
- Check the **library version is compatible with the Angular version** of the project;
