# Comparativo entre Angular 9 e 10

The main differences between the versions are:

| ***Angular 9*** | ***Angular 10*** |
| ---------- | --------- |
| ***TypeScript 3.7*** | ***TypeScript 3.9*** |
| Introduction to the ***Ivy***  | Code conversion ***Pré-Ivy*** |
| ***Service Worker*** Update | Compiler updates |
| ***Language Service*** Improvement | ***Language Service*** Stability |
| (i18n) Improvements | ***TSLib 2.9*** |
| Dependency Injection Changes to ***Core*** | TSLint v6*** |
| ***ModuleWithProviders*** | Translation Improvements (Localization) |
| ***Extractor API Updates*** | New Default Setting for Browser Support |
| ***Component Harness*** | Depreciation of ***ESM5*** and ***FESM5*** packages |
| `ng update` command is now more reliable | Strict Settings for New Projects |

And regarding the compatibility of your ecosystem:

| ***Angular 9*** | ***Angular 10*** |
| --------------- | ---------- |
| **Webpack***: 4.42.0 | ***Webpack***: 4.44.1 |
| **TypeScript***: ~3.8.3 | ***TypeScript***: ~4.0.2 |
| ***RxJs***: ~6.6.7 | ***RxJs***: ~6.6.0 |
| ***jasmine***: ~3.5.0 | ***jasmine***: ~3.6.0 |
| ***karma***: ~5.0.0 | ***karma***: ~5.0.0 |
| ***node***: 10.13.x/12.11.x | ***node***: 10.13.x/12.11.x  |
