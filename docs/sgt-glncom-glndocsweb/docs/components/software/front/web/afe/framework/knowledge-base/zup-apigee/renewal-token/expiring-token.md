# ***Renewal Token*** Expiring

> **❗ Information**
>
> This documentation originated from the resolution of the call [AFE-973](https://jira.santanderbr.corp/browse/AFE-973)

If the coexistence token is **expiring** ahead of time and returning the ***401***** status in the ***refresh_token*** operation to the ***endpoint*** ***auth_convivencia/token/***, the ***state manager*** must be requested to adjust the time via:

[opening call to CDG team](https://jira.santanderbr.corp/projects/SCDGHUBBR/).
