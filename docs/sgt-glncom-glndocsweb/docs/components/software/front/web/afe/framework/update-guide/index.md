# Obsolescence

This session aims to **guide projects to update Angular** to one of the [approved versions](./versioning/approved-versions.md), according to the [versioning](./versioning/index.md) strategy adopted by the front-end architecture.

Updating your project **guarantees**:

- **Compliance** according to our [obsolescence policy](./versioning/obsolescence-policy.md);
- **Support** from architecture to compliant projects;
- **Standardization** of the project, facilitating its **evolution**.

> Upgrading to version requires **manual procedures** that must be performed by the channel, as described in [update policy](./versioning/update-policy.md).
