# Local environment

This session is intended to provide guidance for problems encountered during the assembly of the local environment on the developers' machines.

## 🎯 Overview

Errors related to the on-premises environment can be related to:

- **Lack of knowledge** about **particulars of the operating system** used;
- **Problems in the installation of the software** used;

## 📋 Initial Checklist

- Follow the documentation available on [Environment Configuration](../../getting-started/setup/index.md);

## 🎯 Mapped Scenarios
