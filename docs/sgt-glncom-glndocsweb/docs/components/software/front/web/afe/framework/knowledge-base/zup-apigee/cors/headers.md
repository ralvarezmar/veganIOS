# Configuration of ***Headers***

## Contextualization

One of the reasons why **CORS errors** occur during coexistence is due to the lack of configuration of the ***headers*** that must be exposed.

## Solution

In this case, it is necessary to [open a ticket to the CDG](https://jira.santanderbr.corp/projects/SCDGHUBBR/), requesting the configuration of the ***header*** **Access-Control-Expose-Headers**, described in:

[how to configure the headers for coexistence between zup and apigee](../../../development-guides/deployment/headers/zup-apigee.md)
