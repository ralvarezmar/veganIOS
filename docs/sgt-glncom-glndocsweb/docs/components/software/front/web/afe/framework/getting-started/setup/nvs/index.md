# NVS Configuration

The ***NVS*** (***Node Version Switcher***) is a cross-platform tool for switching between different versions of [Node.js](http://nodejs.org) on the same workstation.

**🎓 What will you learn?**

- [Pre-reqs](./pre-reqs.md)
- [Install](./install.md)
- [Including node version](./including-version.md)
- [Using node version](./using-version.md)
- [Configuring NPM](./configuring-npm.md)

> **🎓Did you know?**
>
> ***NVS*** is similar to [***NVM***](https://github.com/creationix/nvm), but is built to work in ***Windows*** and ***UNIX*** (***Linux*** and ***MacOS***) environments with the same binary.
>
> For more details about the tool, please refer to the [official ***NVS***](https://github.com/jasongin/nvs) repository.
