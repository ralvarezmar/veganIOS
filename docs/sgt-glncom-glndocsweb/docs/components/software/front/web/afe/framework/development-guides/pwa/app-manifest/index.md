# Web App Manifest

The Web App Manifest is one of the most important requirements for developing PWAs and consists of a file called manifest.json that provides information about a particular web application.

So that it can be installed on a device's home screen without having to download it from an app store.

> Originally, the extension specified to create a manifest is ***.webmanifest***, but most browsers support manifests with the ***.json*** extension
