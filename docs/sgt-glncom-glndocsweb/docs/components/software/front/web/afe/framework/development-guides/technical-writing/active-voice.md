# Verbal voice

The form taken by the verb to indicate how the subject of the sentence deals with the action defined by the verb is very important to give the appropriate tone to the text.

In this session, we will get to know the passive and active voice, remembering that the one indicated for technical texts is always the active voice, as it is more direct and objective.

Good sentences in technical documentation identify in a very straightforward way who is doing what for whom.

## Active Voice

In the active voice sentence, the subject performs the action expressed by the verb, following the formula **actor + verb + objective**.

It should be used when we want to make the author stand out:

> The user must install the new version
>
> author: The user
>
> verb: install
>
> goal: the new version

## Passive Voice

Following the opposite of the active voice, in the passive voice the subject undergoes the action expressed by the verb, following the inverse formula of the active voice, the formula of the passive voice being **objective + verb + author**.

We use the passive voice when we want to make the goal clear:

> The **new version** must be **installed** by the **user**
>
> goal: the new version
>
> verb: install
>
> author: The user

## What about imperative verbs?

Do they indicate passive voice or active voice? Imperative verbs are typically active (active voice) It is common to misclassify sentences that begin with an imperative verb as passive.

An imperative verb is a command. Many items in numbered lists begin with imperative verbs.

> ***Open*** the configuration file.
>
> ***Define*** the package-lock variable to true.
>
> 'Open' and 'Define' are both imperative verbs.

Sentences that begin with an imperative verb are usually in the active voice, even if they don't explicitly mention an actor. Instead, sentences that begin with an imperative verb imply an actor. The implicit actor is the reader.

## Distinguishing Between Less Obvious Sentences of Passive Voice and Active Voice

In some cases, the difference between passive voice and active voice sentence is not so simple because the sentence structure is similar and the difference is only the verb:

> 1 - Javascript code is interpreted by the V8 engine
>
> 2 - The V8 engine interprets the Javascript code

What is the passive voice and what is the active voice?

Example 1 the verb is passive because it is not in the imperative. On the other hand, the verb 2 is active voice because it is in the imperative.

> ### 💭🤔 But... Which one should I use when writing documentation?

Use the active voice most of the time. Use the passive voice sparingly.

Most readers mentally convert the passive voice into an active voice. Why subject your readers to extra mental processing time?
The passive voice obfuscates your ideas, turning sentences upside down.

The passive voice reports the action indirectly.

Some passive voice sentences completely omit an actor, which forces the reader to guess the actor's identity. The active voice is usually shorter than the passive voice.
