# Overview

As seen earlier, PWA (Progressive Web App) seeks to make the user experience similar to native apps on desktop and mobile devices, without requiring a separate bundling or distribution.

Your publication is the same as any web page publication.

It works in any browser, but with features similar to native apps, such as:

- Connectivity independence;
- Installation on the home screen;
- Sending [***push notifications***](https://developers.google.com/web/ilt/pwa/introduction-to-push-notifications) (depending on browser support);
