# ***Node Package Management***

Every ***JavaScript*** project needs at least one ***npm*** package, unless you like to do things the hard way. Extensions will help you work with ***npm*** package management more easily.

## [npm IntelliSense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.npm-intellisense)

**License:** MIT

This extension provides ***npm*** modules for autocomplete and import instructions.

## [Path IntelliSense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.path-intellisense)

**License:** MIT

This extension autocompletes the file names. It also works inside ***HTML*** and ***CSS*** files.
