# Advantages and disadvantages of a PWA

## Advantages

The advantages of creating a PWA are:

- Rapid development;
- Can be used regardless of browser or device;
- They work ***offline*** thanks to the ***service worker***;
- Allows you to send ***push notifications***;
- Allows you to add an icon on the device's home screen;
- Updates automatically;
- Experience similar to a native app.
- Takes up less storage space than regular apps;
- No download required, as the functions are executed by the browser, without the need to download an app;

## Cons

Despite all the advantages listed above, PWAs have some disadvantages:

- You can't add them to the app stores;
- ***Web interface*** may lose performance in heavier applications;
- It may not pass the legitimacy of a mobile application;
- Support ***cross-browser***(has partial compatibility with Safari);
- They are not in sync with other applications;
