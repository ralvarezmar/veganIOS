# Comparison between Angular 8 and 9

The main differences between the versions are:

| ***Angular 8*** | ***Angular 9*** |
| --------- | ---------- |
| ***TypeScript 3.4*** | TypeScript 3.7*** |
| ***Ivy engine***| Introduction to Ivy |
| ***Lazy Loading*** | ***Service Worker Update*** |
| ***CLI*** Workflow Improvements | ***Language Service*** Enhancement |
| ***Web Workers*** | Internationalization Enhancements (***i18n***) |
| ***Differential loading*** | ***ModuleWithProviders*** |
| ***Improved Web Worker Packaging*** | ***Component Harness*** |

And regarding the compatibility of your ecosystem:

| ***Angular 8*** | ***Angular 9*** |
| --------------- | ---------- |
| ***Webpack***: 4.39.2 | ***Webpack***: 4.42.0 |
| ***TypeScript***: ~3.5.3 | ***TypeScript***: ~3.8.3 |
| ***RxJs***: ~6.4.0 | ***RxJs***: ~6.6.7 |
| ***Jasmine***: ~3.4.0 | ***Jasmine***: ~3.5.0 |
| ***karma***: ~4.1.0 | ***karma***: ~5.0.0 |
| ***node***: 8.x.x/10.x.x | ***node***: 10.13.x/12.11.x |
