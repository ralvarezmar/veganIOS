# Pipes (Angular 16)

## Prerequisites

- There are no Prerequisites.

## Installing

``` BASH
npm install --save @afe/pipes@^4
```

## Configuration

Import the structuring element into the main module of the project:

``` TS
//app.module.ts
import { PipesModule } from '@afe/pipes';

@NgModule({
  imports: [
    PipesModule,
  ],
})
export class AppModule { }
```

## Implementation

Mention the name of the pipe right after the **pipe operator** that is in front of the data to be formatted, as shown in the example below:

```html
<div>
  <h1>
    Welcome to {{ title }}!
  </h1>
  <strong>Formatação de CPF:</strong>
  <p>Pipe: {{ cpf | afeCpfFormat }}</p>
</div>
```
