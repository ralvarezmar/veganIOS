# Browser Builder

The Builder is in charge of running the build process for projects classified as ***application*** and ***element***.

This process results in the creation of a directory, commonly referred to as a 'dist', that contains the project's code compiled and prepared to be deployed to a specific environment.

The table below lists the different types of projects and their associated Builders. For each type of project, there is a link to access the corresponding documentation.

| Type of Project | Builder |
| --------------- | ------- |
| Application | [Access documentation for ***application***](./application.md) |
| Element | [Access documentation for ***element*** projects](./element.md) |
