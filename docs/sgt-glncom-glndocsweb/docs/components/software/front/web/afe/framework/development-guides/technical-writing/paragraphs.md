# Paragraphs

## Summarize the paragraph in the first sentence

Make your article attractive from the start, invest your writing energy with good opening sentences.

But, what would be a "good way" to start a paragraph?

The first sentence should contain the central subject of the paragraph. This helps the person reading your text to be able to navigate easily between paragraphs.

It's very frustrating to read an article looking for some one-off information and not be able to, because the text doesn't make it easy to read quickly.

How about an example of a paragraph with a proper beginning?

✅ > **Proper First Sentence**
>
> A loop executes the same block of code multiple times. For example, suppose you have written a block of code that detects whether an input line ends with a period. To evaluate a million input rows, create a loop that runs a million times.

Notice that the first sentence explains exactly what the paragraph is about. That way, it's easy to find what you're looking for in the text, without having to read it all.

Now let's look at an example of a confusing paragraph with a first sentence that makes it difficult to identify, whose end result is the same as the first sentence:

❌ > **First sentence outside the scope of the paragraph**
>
> "A block of code is any set of contiguous code within the same function. For example, suppose you have written a block of code that detects whether an input line ends with a period.
> To evaluate a million input rows, create a loop that runs a million times."

It doesn't even seem like we've changed just one sentence, does it? The paragraph gets messy when the first sentence is not adequate. So, pay attention to the first few sentences of your paragraphs!

## Each paragraph should deal with a single topic

Have you ever heard of Single Responsibility, one of S.O.L.I.D.'s best practice concepts? For our paragraphs, we're going to follow the same idea! Each paragraph should account for only one

Don't describe what will happen in a later paragraph or what happened in a previous paragraph. Delete or move to another paragraph any sentence that is not directly related to the current topic.

## Write consistent paragraphs: not too long, not too short

Long paragraphs intimidate and discourage reading. Short paragraphs can go unnoticed. Readers usually like paragraphs that are between **3 and 5 sentences** but usually avoid paragraphs with more than 7 sentences.

If your paragraph contains only one sentence, try to fit it into another paragraph, but don't leave the sentence "loose" without context.

## Answer the what, why, and how

Paragraphs should answer three questions:

What are you trying to say to those who read your text?
Why is it important for this person to know this?
How should she use this knowledge, and then how can she confirm that her argument is true?

> **What**: Angular was the framework of choice for the front-end architecture
>
> **Why**: due to the arsenal of features and tools for creating and updating large-scale projects, in addition to its modularization and opinionated aspect.
>
> **How**: Angular makes it easy to update and standardize applications.
