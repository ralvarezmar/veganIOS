# Encryption (Angular 8, 10 and 12)

## Prerequisites

### Functional

- Installing [***@afe/http-interceptors***](./../../http-interceptors/v3/index.md);
- Configuration of the [***HubConnectorInterceptor***](./../../http-interceptors/v3/modules/hub-connector-interceptor.md) to the **communication** process with the Services Hub.

### Non-functional

- Request permission to consume the Key Exchange API from [Service Hub](https://confluence.santanderbr.corp/display/PADROESARQINT/Suporte).

## Installation

``` BASH
npm install @afe/encryption@^2
```

## Configuration

- See the [available modules](./modules/index.md) to implement the functionalities provided by the designer in your project.
