# **Architecture Libraries** Knowledge Base

Session created with the purpose of documenting all the errors already recorded on the topic of **Architecture Libraries**.

## 🎯 Overview

Errors related to architecture libraries can be related to:

- Implementation or misconfiguration of the library. This scenario applies when there is **inattention in reading** or there is **absence of information** in the documentation;
- **Library version incompatible with Angular version**;
- Library not supported by the architectural model of the project;

## 📋 Initial Checklist

Before proceeding to the mapped scenarios we have documented, follow the checklist to recap the procedure required to use the architecture libraries:

- *lease review the [library technical documentation](../../architecture-libraries/index.md) or follow the [functional guide](../../development-guides/index.md).

- If available; **Pay attention to the details** of **configuration and implementation**, based on the project's architecture;

- Make sure your project has a **library version that is compatible** with the **Angular version**;
