# Angular update policy

When updating a project, channels must be aware that the procedures listed below **are not performed by Angular nor by the front-end architecture (AFE)**:

- **Update of third-party libraries**: libraries that are not part of the architecture must be updated manually by the project. Ex: ***formalizacao***, ***perseus***, ***ng2-translate***, ***@dss***
- **Manual updates of architectural parts**: during the migration of architectural parts, some steps were automated, while others must be done manually, through migration documentation for each part.
- **Manual project updates:** some updates are specific to each project and must be carried out manually, following the instructions provided in the [update guides](../index.md).
