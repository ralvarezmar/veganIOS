# Roadmap

Service Workers are opening doors to great features such as:

- Push Notifications: Allow users to accept timely updates from web applications.
- **Background Sync**: Allows you to postpone actions until the user has stable connectivity. This way, you can be sure that whatever the user wants to send, is actually sent.
- **Periodic Sync (FUTURE)**: ***API*** that provides functionality to manage periodic background sync.
- **[Geofencing](https://maplink.global/blog/o-que-e-geofencing/) ( FUTURE )** : You can set parameters, also known as ***geofences*** that surround the areas of interest.

The web app receives a notification when the device crosses a geofence, which allows you to provide a useful experience based on the user's geography.
