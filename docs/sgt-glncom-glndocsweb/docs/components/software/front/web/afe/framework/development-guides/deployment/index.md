# ***Deployment***

Deployment*** is the process that involves moving the software into the development, approval, and production environments. This phase concentrates all the necessary settings for the application to run correctly. It is divided into 4 basic steps:

- **Hosting**: Definition of where your application will live.
- Domain: How users will find your application.
- **Environment**: All the preparation for the hosting server to receive your application.
- **Optimization**: Improvements to the environment to optimize application performance.
