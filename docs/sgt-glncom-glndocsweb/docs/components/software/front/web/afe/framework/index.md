# Arquitetura de Front-End (AFE)

**AFE** uses *Angular* and its *ecosystem* as the main tool to design features as a whole to facilitate the development of applications across channels.
AFE was initially developed by **f1rst (Santander Brasil)** and now used by the whole Santander Group under the *Gluon initiative*.

The very first step in the Gluon roadmap is to **acquire AFE "as is"** and then, **evolve it towards a convergency with Darwin**, conforming a unique frontend framework for all the Santander Group.
