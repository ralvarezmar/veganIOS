# How to update the architecture components

Below you will find the new versions of the **architecture components** compatible with **Angular version 18**, followed by the respective commands to update the package in your project.

> Execute **only** the command for the packages **defined** in the application's ***package.json***.

| Component | Update Command |
| --------- | --------------- |
| [**@afe/cli**](../../architecture-libraries/afe/cli/index.md) | `npm i @afe/cli@18` |
| [**@afe/http-interceptors**](../../architecture-libraries/afe/http-interceptors/index.md) | `npm i @afe/http-interceptors@18` |
| [**@afe/authentication**](../../architecture-libraries/afe/authentication/index.md) | `npm i @afe/authentication@18` |
| [**@afe/encryption**](../../architecture-libraries/afe/encryption/index.md) | `npm i @afe/encryption@18` |
| [**@afe/authorization-manager**](../../architecture-libraries/afe/authorization-manager/index.md) | `npm i @afe/authorization-manager@18` |
| [**@afe/tagging**](../../architecture-libraries/afe/tagging/index.md) | `npm i @afe/tagging@18` |
| [**@afe/websocket-action-runner**](../../architecture-libraries/afe/websocket-action-runner/index.md) | `npm i @afe/websocket-action-runner@18` |
| [**@afe/context-handler**](../../architecture-libraries/afe/context-handler/index.md) | `npm i @afe/context-handler@18` |
| [**@afe/pipes**](../../architecture-libraries/afe/pipes/index.md) | `npm i @afe/pipes@18` |
