# Definitions for words

## Define terms that are unfamiliar

Always ask yourself if the term used in the text is familiar to the majority of your audience.

If the term already exists, refer to the explanation of it through links, avoid explaining what has already been explained by someone.

If the term is new or it is the purpose of the article to explain it, make an objective definition. If your article is going to use a collection of terms, it's best to create a glossary.

## Always use the same nouns or adjectives to refer to terms, avoid confusion

When presenting the name of a concept or definition, avoid changing the word throughout the article, this can hinder the reader's understanding.

If, for example, you started your article using the Pure Javascript definition, avoid using Vanilla to refer to the same thing. Instead, use **Pure Javascript** until the end.

Alternatively, if you need to switch between terms, or if you want to replace the full naming with the use of an acronym, simply make this correspondence explicit. Using the previous example, we could write:

> **Example ✅**
>
> Pure Javascript (*Vanilla JS*)** is, by definition...

## Avoid alternating between acronyms and their meanings

If any definition is too long, it is common to use acronyms, as with the *Hypertext Transfer Protocol*, or ***HTTP***.

The correspondence of acronyms and their meanings should be defined at the beginning of the article, but it is important to avoid alternating between them during the article.

In the example we brought from ***HTTP***, it would be ideal to use only the acronym every time you refer to it, avoiding the definition *"Hypertext Transfer Protocol"* unless it is really indispensable for the understanding of a passage.

Some good practice tips:

- Do not create acronyms for definitions that will only be used very few times in the article;
- Terms whose acronyms are highly recommended:
  - When the acronym will be much shorter than the definition;
  - The acronym will be used many times in the document.

## Use pronouns appropriately when you want to replace a noun

The use of pronouns can replace the use of a noun when the reference is correctly attributed. Otherwise, it will create misinterpretations. In correct usage, we first use the noun, and only then do we apply the pronoun substitution.

> Example ✅**
>
> "John is a programmer. **He** will start work tomorrow"
>
> John - proper noun
>
> He - masculine singular pronoun, which replaces the noun "John".

Leave the pronoun as close as possible to the noun referred to, as in the example we brought. In general, if there is a distance of more than five words between the noun and the pronoun that references it, it is more appropriate to repeat the noun.

Be careful when using two nouns that are very close together and can be referenced with the same pronoun:

> **❌ Bad practice**
>
> "**John** is a programmer and **José** is too. **He** will start work tomorrow" > >It's not clear whether it's Joe or John who's going to start work tomorrow.
