# Including ***node*** versions

> If you're using ***MacOS***, a version of ***Node***, you've probably already added a version.
>
> Check using the `nvs list` command.

To use and ***download*** from ***Node***, simply use the `nvs add<version>` command.

> Replace ***`<version>`*** with the version of ***Node*** you want to install.

```powershell
nvs add 14
```

If you want a specific version, just mention in the command:

```powershell
nvs add 14.12.0
```
