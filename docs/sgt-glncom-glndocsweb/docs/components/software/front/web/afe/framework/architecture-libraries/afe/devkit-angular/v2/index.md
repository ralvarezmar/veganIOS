# Angular Devkit (Angular 16)

## Prerequisites

- Installing [***@afe/cli***](../../cli/index.md)

## Installation

```bash title='Terminal'
npm install --save @afe/devkit-angular^2 --save-dev
```

## Implementation

- See the [available builders](./builders/index.md) to set up AFE's custom *builders*, which are responsible for encapsulating the calls of the original angular builders with the addition of some internal processes
