# Architecture Types

We currently have two types of architecture available, namely:

- **SPA (Single Page Application)**: It is a web application that consists of only **one page** where its content is dynamically modified, in order to offer an experience similar to that of a desktop application.
- **MFE (Micro Front-end)**: It is a concept based on micro-services oriented to web applications, allowing them to be decomposed into **decoupled** and **self-contained** modules.**

> To delve deeper into the terms used, see [differences between Monolithic SPA and MFE](./spa-vs-mfe.md).
