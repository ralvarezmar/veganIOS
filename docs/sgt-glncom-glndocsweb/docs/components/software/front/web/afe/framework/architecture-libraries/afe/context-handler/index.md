# Context Handler

The ***@afe/context-handler*** is a library responsible for managing ***session*** or ***workspace*** context data.

## Compatibility

Using the table below and based on the version of Angular in your project, follow the **steps described in the documentation** for **installation** and **configuration** from the version of the designer.

| Angular Version | Library version |
| ----------------- | ---------------------- |
| v16 | [v4](./v4.md) |
| v8 v10 | [v3](./v3.md) |

## Installation

```bash
npm install @afe/context-handler@^4 --save
```
