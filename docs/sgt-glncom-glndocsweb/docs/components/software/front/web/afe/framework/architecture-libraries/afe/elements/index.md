# Elements

The ***@afe/elements*** is a library with modules for various resources for an application of type element of the Frontend Architecture.

The piece is composed of features integrated with Angular and aims to facilitate the development of applications of the micro front-end architecture in the bank's environment.

## Compatibility

Using the table below and based on the version of Angular in your project, follow the **steps described in the documentation** for **installation** and **configuration** from the version of the designer.

| ----------------- | ------------------------ |
