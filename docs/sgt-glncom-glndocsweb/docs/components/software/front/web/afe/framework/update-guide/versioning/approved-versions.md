# Versions approved by AFE

We currently provide **active support for version 16 of Angular**.

Version 12 is in LTS (Long Term Support) status, where we still provide support for **fixes in production**.

> ⚠️ **Attention!**
>
> Dates are offered as a general guide and are subject to change.

## Active and LTS version

The link between active support and LTS occurs at even releases.

> An active version when support ends becomes an LTS version.

| Angular | Status | End of Support |
| ------ | ------ | ------------------ |
| 16 | Activate | 12/2025 |
| 12 | LTS | 12/2024 |

## Non-approved versions

## Version of ***NodeJS***

Pay attention to the version of ***NodeJS*** used.

We currently recommend the ***16*** version of ***Node*** to be used.

For more information, consult the following documentation:

- **Local**: [how to configure the node version locally from NVS (Node Version Switcher)](../../getting-started/setup/nvs/index.md).

## Obsolete versions

The versions below are obsolete, and therefore we do not provide any support.

| Angular | Status | End of Support |
| ------ | ------ | ------------------ |
| 10 | Obsolete | 12/2023 |
| 8 | Obsolete | 12/2021 |
| 7 | Obsolete | 12/2020 |
| 5 | Obsolete | 12/2020 |

Pay attention to the need to adapt your project to the active version or at least LTS.
