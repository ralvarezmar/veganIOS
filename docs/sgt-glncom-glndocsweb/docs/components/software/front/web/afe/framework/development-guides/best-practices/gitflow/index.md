# What is Git Flow?

Git Flow is a development flow model for the branches of a project, which consists of the use of feature branches (features, fixes) and main branches (development, release).

It was first published and popularized by [Vincent Driessen](https://nvie.com/posts/a-successful-git-branching-model/).

Git Flow is just an abstract idea of the Git workflow, meaning it dictates what types of branches to set up and how to merge <https://www.atlassian.com/br/git/tutorials/using-branches/git-merge>.

> For more information, read about [workflow with ***Git Flow***](https://www.atlassian.com/br/git/tutorials/comparing-workflows/gitflow-workflow).
