# Lists e tables

The 3 types of lists are most common in technical articles:

- Bulleted lists
- Numbered lists
- Embedded lists

Use a bulleted list for items that don't need to be in order. Use a **numbered list** for items that need to be ordered to make sense.

Inline list contains items inserted into a sentence. For example, the following sentence contains an embedded list with four items.

❌ > **Built-in list**
>
> "The Payments API allows you to create and query payments, analyze statements, delete records, and track transaction ids."

But beware: the built-in list is not the best way to convey information. It's more effective to turn it into a bulleted list.

✅ > **Bulleted List**
>
>"The Payments API allows you to:
>
> - Analyze Statements
> - Delete records
> - Track Transaction IDs
> - create and query payments"

## Create Coherent Lists

In addition to choosing the most appropriate format, observe if the elements of your list are "parallel", that is, if the themes have the same "format". In the previous example of the payments API list, we have an unordered list of phrases.

This is a coherent list because it has only sentences. Think of a shopping list:

✅ > **coherent list**
>
>Shopping List
>
> - tomatoes
> - onions
> - Carrots

In this example, the list is also coherent because we only have words. Now, let's look at an example of a list that doesn't have a lot of format in coherence, because it mixes items with sentences:

❌ > **Incoherent Format List**
>
> The Payments API allows you to:
>
> - Create and view payments
> - Analyze
> - Delete
> - Track

It would be more coherent to add what the API parses, deletes and tracks, or keep the same pattern as the first element, dividing it into "create" and "query".

Also note that the "delete" item was written with the first letter capitalized, unlike the rest of the list.

The first item on the list should set the standard for all other elements.

## Start numbered lists with imperative verbs

An imperative verb is a command, such as "install" and "read." Keep all items also with the same type of verb at the beginning, this will make your lists coherent.
