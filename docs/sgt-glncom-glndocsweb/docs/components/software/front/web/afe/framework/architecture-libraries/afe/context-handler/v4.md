# Context Handler (Angular 16)

## Prerequisites

- There are no prerequisites.

## Installation

Its installation contemplates different architectural scenarios, as shown in the steps below.

### Common SPA Project

``` BASH
npm install --save @afe/context-handler^4
```

### MFE Project

#### MFE App Installation

``` BASH
npm install --save @afe/context-handler^4
```

#### Base and Lean Installation

``` BASH
npm install @afe/context-handler^4 --save-dev
```

And finally, add in ***peerDependencies*** inside ***projects/library-name/package.json*** of your **base** or **lean**, respecting the **most current version** of the structuring installed with the ***npm install*** command:

```json
"peerDependencies": {
    "@afe/context-handler": "{major}.{minor}.{patch}"
}
```

## Usage

### Configuration

To configure ***@afe/context-handler*** simply import the module ***ContextHandlerModule*** into the main module of the project

> If it's a SPA project, it's usually the ***AppModule***
>
> If it's an MFE project, it's usually the ***BaseFrontModule*** of the base of the channel

And you also need to use the ***forRoot*** method by passing an object of type ***ContextConfig*** that has the following properties:

| Name | Description |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **contextName**: ***string*** | Setting the Session Context Principal Name |
| **contextSessionKeys**: ***`Array<string>`*** | List of session context keys to be pre-initialized when loading the application |
| **contextWorkspaceKeys**: ***`Array<string>`*** | List of workspace context keys to initialize when creating a workspace |
| **middleware?**: ***`Array<Middleware>`*** | List of functions, containing a data handling logic, to be executed whenever a context key is updated |
| **keyMappingConfig?**: ***KeyMappingConfig*** | Context Key Mapping Configuration |

Configuration example:

```typescript
// example-middleware.ts
import { of } from 'rxjs';

import { Middleware, MiddlewareParams } from '@afe/context-handler';

export function exampleMiddleware(params: MiddlewareParams) {
    return of({
        ...params.value,
        editData: params.value.editData + '-edited'
        customData: 'novaPropriedade'
    });
}

export const contextMiddlewares: Array<Middleware> = [
    exampleMiddleware,
];
```

```typescript
// context-handler.config.ts
import { ContextConfig, KeyMappingConfig } from '@afe/context-handler';

import { contextMiddlewares } from './example-middleware.ts';

export const keyMappingConfig: KeyMappingConfig = {
    default: {
        ['WORKSPACE_CONTEXT.customData']:
            'WORKSPACE_CONTEXT.contextData',
    },
    'workspace-lean': {
        ['WORKSPACE_CONTEXT.customWorkspaceLeanData']:
            'WORKSPACE_CONTEXT.contextData',
    },
};

export const contextHandlerConfig: ContextConfig = {
    contextName: 'base',
    contextSessionKeys: ['SESSION_CONTEXT'],
    contextWorkspaceKeys: ['WORKSPACE_CONTEXT'],
    middlewares: contextMiddlewares,
    keyMappingConfig,
};
```

### Implementation

### SessionContextService

Used to manage session-wide context data. The keys previously configured in the configuration of the ***contextSessionKeys*** property are automatically initialized at the time the application is loaded

To use it, it must be injected into the classes that will take advantage of this type of context

```ts
constructor(private sessionContextService: SessionContextService) { }
```

In a certain part of the application, the value of a context key can be updated

To do this, we will use the ***updateValue*** method, which receives a parameter object of type `DespatchData<T>` which has the following properties:

| Name | Description |
| ------------------------ | ------------------------------------------------------------------------------------------------------- |
| **key**: ***string*** | Context Key Identifier |
| **value**: ***T*** | Value to update in the context key. Can be any type (***string***, ***number***, ***boolean***,***object***) |
| **debounce?**: ***number*** | Delay to effect context key value update |

Example of use:

```ts
this.sessionContextService.updateValue({
    key: 'sessionContext',
    value: 'exemplo'
}).subscribe();
```

> It is important that the ***subscribe*** method is called to effect the update

In this way, one or more parts of the application can retrieve the updated value of the context key

To do this, we will use the ***getValue*** method, which receives a ***string*** parameter which is the identifier of the context key

Example of use:

```ts
this.sessionContextService.getValue('sessionContext')
    .subscribe((result) => {
        console.log(result); // output: 'exemplo'
    });
```

> If the key you want to query is not yet updated with a value, it will have the value ***undefined***

### LeanContextService

Used to manage the context data of a lean. To use this service it is necessary to configure the ***ContextHandlerModule*** in the main lean module using the ***forChild*** method passing an object of type LeanContextConfig that has the following properties:

| Name | Description | | ------------------------------------- | ---------------------------------------------------------------------------------------- |
| **leanName**: ***string*** | Used to identify lean |
| **contextLeanKeys?**: ***`Array<string>`*** | List of Lean Context Keys to Pre-Initialize When Loading Lean |

Configuration example:

```typescript
// context-handler.config.ts
import { LeanContextConfig } from '@afe/context-handler';
```

### Middlewares

In order to allow the processing of the context data that is being updated before performing the update, the configuration of ***middleware*** was created

```typescript
// example-middleware.ts
import { of } from 'rxjs';

import { Middleware, MiddlewareParams } from '@afe/context-handler';

export function exampleMiddleware(params: MiddlewareParams) {
    return of({
        ...params.value,
        editData: params.value.editData + '-edited'
        customData: 'novaPropriedade'
    });
}

export const contextMiddlewares: Array<Middleware> = [
    exampleMiddleware,
];
```

```typescript
// context-handler.config.ts
import { ContextConfig } from '@afe/context-handler';

import { contextMiddlewares } from './example-middleware.ts';

export const contextHandlerConfig: ContextConfig = {
    // demais configurações omitidas
    middlewares: contextMiddlewares
};
```

In this way, when using the ***updateValue*** method, a treatment will be done before storing the values of the context key

```ts
this.workspaceContextService.updateValue({
    key: 'workspaceContext',
    value: {
        editData: 'toEdit'
    }
}).subscribe();
```

When retrieving the value of the context key using the ***getValue*** method, the value is already handled

```ts
this.workspaceContextService.getValue('workspaceContext')
    .subscribe((result) => {
        console.log(result); // output: '{ customData: 'newProp', editData: 'toEdit-edited' }'
    });
```

### KeyMappingConfig

In order to make it possible to do a key mapping, when different parts of the application request information but use different keys, the configuration of ***keyMappingConfig*** was created

```typescript
// context-handler.config.ts
import { ContextConfig, KeyMappingConfig } from '@afe/context-handler';

import { contextMiddlewares } from './example-middleware.ts';

export const keyMappingConfig: KeyMappingConfig = {
    default: {
        ['workspaceContext.customData']:
            'workspaceContext.contextData',
    },
    'workspace-lean': {
        ['WORKSPACE_CONTEXT.customWorkspaceLeanData']:
            'WORKSPACE_CONTEXT.contextData',
    },
};

export const contextHandlerConfig: ContextConfig = {
    // demais configurações omitidas
    keyMappingConfig,
};
```

For this to be possible, it is necessary to configure the ***ContextHandlerModule*** module using the ***forChild*** method, as explained in the section on [***LeanContextService***](#leancontextservice)

When the value of the context key is updated

```ts
this.workspaceContextService.updateValue({
    key: 'workspaceContext.contextData',
    value: 'exemplo'
}).subscribe();
```

It can be retrieved either by the original key identifier or by the configured mapping identifiers, whether general or lean-specific

```ts
this.workspaceContextService.getValue('workspaceContext.customData')
    .subscribe((result) => {
        console.log(result); // output: 'exemplo'
    });

this.workspaceContextService.getValue('workspaceContext.customWorkspaceLeanData')
    .subscribe((result) => {
        console.log(result); // output: 'example'
    });
```
