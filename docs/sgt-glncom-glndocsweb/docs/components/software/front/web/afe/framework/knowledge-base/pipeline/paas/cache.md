# How to troubleshoot caching issues when performing a new deployment

Some projects, when performing a new deployment, may find the browser screen blank and the main Angular files returning the status [404 Not Found](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/404).

## Contextualization

This problem occurs due to the server not retrieving the correct modification date of the files generated by Angular, causing it to request the old files that no longer exist on the server.

## Solution

Go to the project's Dockerfile and check the line that instructs you to configure the nginx image, as shown in the example below, and change it to 1.21:1.1.0.RELEASE.

```diff
###############
## APLICACAO ##
###############

- FROM artifactory.santanderbr.corp/docker-base/nginx-1.13:3.1.0.RELEASE
+ FROM artifactory.santanderbr.corp/docker-base/nginx-1.25:1.0.1.RELEASE
```

This will update the version of the ***nginx*** image that fixes the problem with the date the files were modified.

After performing the update on the Dockerfile, just perform a new deployment.
