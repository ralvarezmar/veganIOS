# How to update the architecture structuring

Below you will find the new versions of the **structuring** of the architecture compatible with **version 12 of Angular**, followed by the respective commands to update the package in your project.

> Run **only** the command from the **defined** packages in the application`s ***package.json*** packages.

| Structuring | Update Command |
| ------------ | ---------------------- |
| **@afe/http-interceptors** | `ng update @afe/http-interceptors@3` |
| **@afe/cli** | `ng update @afe/cli@3` |
| **@afe/authentication** | `ng update @afe/authentication^1.1.0` |
| **@afe/encryption** | `ng update @afe/encryption@^2.5.0` |
| **@afe/authorization-manager** | `ng update @afe/authorization-manager@4` |
| **@afe/tagging** | `ng update @afe/tagging@3` |
| **@afe/websocket-action-runner** | `ng update @afe/websocket-action-runner@^3.1.0` |
| **@afe/context-handler** | `ng update @afe/context-handler@^3.1.0` |
| **@afe/pipes** | `ng update @afe/pipes@^3.1.0` |
| **@afe/elements** | `ng update @afe/elements@^1.3.0` |
| **@afe/devkit-angular** | `ng update @afe/devkit-angular@^1.2.0` |
