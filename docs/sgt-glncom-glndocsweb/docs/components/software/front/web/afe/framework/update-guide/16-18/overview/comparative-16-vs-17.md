# Comparison between Angular 16 and 17

The main differences between the versions are:

| ***Angular 16*** | ***Angular 17*** |
| --------- | ---------- |
| Supported NodeJS versions: **16.14** and **18.10**.  | Supported NodeJS versions: **18.13** and **20.9**. |
| Support for TypeScript **4.9**, **5.0**, and **5.1**. | Support for TypeScript **5.2**. |
| ***Webpack*** is the default *builder*. | ***Vite*** and ***esbuild*** are the default *builders*. |
