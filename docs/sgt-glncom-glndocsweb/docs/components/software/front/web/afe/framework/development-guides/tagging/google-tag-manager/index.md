# Tagging with Google Tag Manager

Google Tag Manager is a powerful tool that allows you to send events and on-page interactions to Google Analytics. This makes it easier to capture and analyze user behavior, making your strategies and user experience more effective.

They are used so that performance people can set up studies and dashboards to understand what works or doesn't work in certain flows.
