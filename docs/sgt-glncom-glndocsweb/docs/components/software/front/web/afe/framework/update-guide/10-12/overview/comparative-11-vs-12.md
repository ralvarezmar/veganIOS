# Comparative between Angular 11 e 12

The main difference between the versions:

| ***Angular 11*** | ***Angular 12*** |
| --------- | ---------- |
| Removing Internet Explorer 9, 10 and Mobile Internet Usage | IE11 Support Suspension |
| Strict mode activated via ***flag*** `--strict` | Strict Mode by Default |
| Improved ***Ngcc*** Compiler | Enhanced Logging & Reporting |
| Updated Language Service Preview | Updated Language Service Preview |

Compatibility between eco systems:

| ***Angular 11*** | ***Angular 12*** |
| --------------- | ---------- |
| ***Webpack***: 4.44.2  | ***Webpack***: 5.50.0 |
| ***TypeScript***: ~4.1.5 | ***TypeScript***: ~4.3.5 |
| ***RxJs***: ~6.6.0 | ***RxJs***: ~6.6.0 |
| ***jasmine***: ~3.6.0 | ***jasmine***: ~3.8.0 |
| ***karma***:  ~6.1.0 | ***karma***: ~6.3.0 |
| ***node***: 10.x.x/12.x.x | ***node***: 12.x.x/14.x.x |
