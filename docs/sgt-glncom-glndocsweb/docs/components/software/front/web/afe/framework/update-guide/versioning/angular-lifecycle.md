# Angular lifecycle

Angular currently has a continuous update cycle, with **new versions being released every six months**.

This update cycle was developed to maintain continuous improvement in the ***framework***, always bringing greater stability and the ability to use new emerging technologies.

> 💡 Curiosity
>
> Learn more about the [Angular update cycle](./angular-update-cycle.md).

The versioning policy is based on [Semantic Versioning](./semantic-versioning.md), making these updates more coherent and less traumatic.

> For more details, see [official Angular documentation](https://angular.io/guide/releases).

Each version of Angular has a **18 month lifespan**, going through ***3*** states: ***Active Support***, ***Long Term Support*** and ***Obsolete***.

In its first six months, the version remains in its active period, receiving updates and corrections necessary to function correctly.

After these six months, it becomes a Long Term Support (LTS) state. An LTS version is already fully approved, it no longer receives new features and its problems have been duly corrected, making it a stable version.

The **LTS period remains for 12 months**, until the version becomes obsolete and **no longer receives any updates, including security fixes**.

> Learn more about [Angular support policy](https://angular.io/guide/releases#support-policy-and-schedule).
