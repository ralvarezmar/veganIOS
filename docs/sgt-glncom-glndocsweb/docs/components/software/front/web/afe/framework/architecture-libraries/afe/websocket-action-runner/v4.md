# Websocket-Action Runner (Angular 16)

## Prerequisites

- There are no Prerequisites.

## Installing

``` BASH
npm i @afe/websocket-action-runner@^4
```

## Configuring

To configure ***@afe/websocket-action-runner*** simply import it into the main module of the application.

The ***forRoot*** method of the ***WebSocketActionRunnerModule*** module receives an object of type ***WebsocketActionRunnerConfig***, having the following properties:

|Property|Type|Description|
|-|-|-|
|***url***|***string***|URL to connect to WebSocket server|
|***protocol***|***string***|Protocol to be used for connection. Can be used ws or wss|
|***port***|***string***|Port that will be used to connect to the server|
|***actions***|***`Array<Type<Action>>`***|Defines actions that will be taken for each type of message sent to WebSocket|
|***autoConnect***|***boolean***|Sets whether to connect to WebSocket to be automatic |
|***keepAlive***| N/A | |
|***KeepAliveConfig*** | ***Boolean***| Configures reconnection and messaging settings for connection maintenance|
|***additionalCallbackList***|***`Type<CallbackList>`*** |Defines additional executions for the WebSocket|
|optional ***context***|***string***|Sets the context of the url|
|optional ***connectionName***|***string***|Defines the name of the connection, used as a key to identify within the active connection pool|
|optional ***encryptionMode***|***EncryptionMode***|Sets the mode of encryption applied on the websocket [ ***NONE***, ***OPTIONAL***, ***REQUIRED***],
|optional ***encryptionEventsKeys***|***EncryptionEventsKeys***|Sets the event names for key exchange with Websocket Server|
|***deprecatedactionsFn***|***ActionFns***|This key was the old ***actions*** property and will be removed in future releases|
|***deprecatedadditionalCallbackFnList***|***CallbackFnList***|This key was the old ***additionalCallbackList*** property and will be removed in future releases|

### Configuration Example

Create a folder called ***websocket*** and inside the central folder of project configuration files (we recommend creating in a ***config***) folder and add to it the following configuration files:

- File ***actions.ts*** containing the classes to be exported for use in the ***actions*** property of a connection.

``` TS
//title=actions.ts
import { Injectable } from '@angular/core';
import { ActionMessage, Action } from '@afe/websocket-action-runner';

@Injectable({ providedIn: 'root' })
export class ClassAction implements Action {

public handle(message: ActionMessage): void {
    console.log('action de classe', message);
    // Implementação Pretendida
}

public resolveActionName(): string {
    return 'classAction';
    }
}
```

- File ***callback-list.ts*** containing the classes to be exported for use in the ***additionalCallbackList*** property of a connection.

    ``` TS
    //title=callback-list.ts
    import { Injectable } from '@angular/core';
    import { CallbackList, ServiceResponse, WebSocketEvent } from '@afe/websocket-action-runner';

    @Injectable({ providedIn: 'root' })
    export class ClassCallbackList implements CallbackList {

        public onOpen(event: WebSocketEvent): void {
            // Implementação Pretendida
        }

        public onMessage(response: ServiceResponse): void {
            // Implementação Pretendida
        }

        public onError(event: WebSocketEvent): void {
            // Implementação Pretendida
        }

        public onClose(event: WebSocketEvent): void {
            // Implementação Pretendida
        }
    }
    ```

- File ***websocket.config.ts*** containing the variable to be exported with the configuration of a connection to form the list of connections of the structuring agent.

    ``` TS
    //websocket.config.ts
    import { ClassAction } from './actions';
    import { ClassCallbackList } from './callback-list';
    import { EncryptionMode, WebsocketActionRunnerConfig } from '@afe/websocket-action-runner';

    export const websocketActionRunnerConfig: WebsocketActionRunnerConfig = {
        encryptionMode: EncryptionMode.NONE,
        connectionName: 'first',
        url: 'localhost',
        protocol: 'ws',
        port: '3001',
        context: 'first',
        actions: [ ClassAction ],
        autoConnect: true,
        keepAlive: true,
        additionalCallbackList: ClassCallbackList,
    };
    ```

- File ***websocket-connections.ts*** containing the variable to be exported with the list of connections for use in the structuring module.

    ``` TS
    //websocket-connections.ts
    import { websocketActionRunnerConfig } from './websocket.config';
    import { WebsocketActionRunnerConfig } from '@afe/websocket-action-runner';

    export const webSocketConnections: Array<WebsocketActionRunnerConfig> = [
        websocketActionRunnerConfig,
        // demais conexões conforme necessário
    ];
    ```

Finally, import the configuration variable containing the connections and pass it as a parameter in the ***forRoot*** method of the ***WebSocketActionRunnerModule***.

``` TS
//app.module.ts
import { NgModule } from '@angular/core';

import { webSocketConnections } from '<caminho-do-arquivo-de-configuração>/web-socket-connections';
import { WebSocketActionRunnerModule } from '@afe/websocket-action-runner';

@NgModule({
    // configuração omitida
    imports: [
        WebSocketActionRunnerModule.forRoot(webSocketConnections),
    ],
})
export class AppModule { }
```

## Implementation

To use the designer, use the WebSocketActionRunnerService*** service for necessary operations, such as sending a message to a connection that has been configured.

``` TS
//websocket-example.component.ts
import { Component, Input, OnInit } from '@angular/core';

import { ActionParam, WebSocketActionRunnerService } from '@afe/websocket-action-runner';

@Component({
    // Configuração Pretendida
})
export class WebsocketExampleComponent implements OnInit {

    constructor(
        private wsActionRunnerService: WebSocketActionRunnerService,
    ) { }

    public ngOnInit(): void {
        // Implementação Pretendida
    }

    public toSend(): void {
        const customParams = {
            "scope": "SERVER_ONLY",
            "<your-param-key>": '<your-param-value>'
        };
        const sendObject: ActionMessage = {
            action: "<your-action-name>",
            eventId: "<your-event-id>",
            correlationId: "<your-correlation-id>",
            source: "<your-source>",
            params: customParams as ActionParam,
        };
        this.wsActionRunnerService.sendActionMessage(sendObject, '<nome-da-conexão-configurada>');
    }
}
```

## Methods

Method | Parameters | Description
----------- | ---- | ---------
**init**: ***void*** | ***N/A*** | Initiates the connection to the server ***WebSocket***
**sendActionMessage** - ***string*** | message: ***ActionMessage***, ***connectionName: string*** | Sends messages to the server
**connectConfig**: ***void*** | _config: ***Config*** | Responsible for making the connection dynamically
**connect**: ***void*** | ***port***, ***url***, ***protocol***, ***context***, ***keepAlive: boolean \| KeepAliveConfig***,
***actions: Actions***,***connectionName: string***, ***additionalCallbackList: CallbackList*** | Responsible for making the connection by optional configuration

``` TS

@Component({
```

### ***sendActionMessage(message: ActionMessage, connectionName: string)***

Sends messages to the server with the following parameters:

|Parameter|Type|Description|
|-|-|-|
|***message***|***ActionMessage***|interface containing the necessary parameters for communication between the ends|
|***connectionName***|***string***|Name of the connection that the message should be sent|
|***ActionMessage***|***string***| String interface is used for websocket communication and contains the following properties |
|***action***| ***string***|Name of the action expected by the server|
|optional ***eventId*** |***string***|Event ID|
|optional ***correlationId***|***string***|Event ID to which this event responds |
|optional ***source***|***string***|Event Source|
|optional ***params***|***ActionParam***|Additional Parameters|
|optional ***body***|***string***|Message Body|

``` TS
//example.component.ts
import { Component, OnInit } from '@angular/core';
import { WebSocketActionRunnerService } from '@afe/websocket-action-runner';

@Component({
    // conteúdo omitido
})
export class ExampleComponent implements OnInit {

    constructor(private wsActionRunnerService: WebSocketActionRunnerService) { }

    public ngOnInit(): void {
        // Conteúdo omitido

        const message: ActionMessage = {
            "action": "<your-action-name>",
            "eventId": "<your-event-id>",
            "correlationId": "<your-correlation-id>",
            "source": "<your-source>",
            "params": {
                "scope": "SERVER_ONLY",
                "<your-param-key>": '<your-param-value>'
            }
        }

        this.wsActionRunnerService.sendActionMessage(message, '<nome-da-conexão-pretendida>');
    }
}
```

### ***connectConfig***

> As an example is pertinent, the variable ***WebsocketActionRunnerConfig*** object of type ***Config*** in the configuration session.

```ts
import { Component, OnInit } from '@angular/core';
import { WebSocketActionRunnerService } from '@afe/websocket-action-runner';
import { websocketActionRunnerConfig } from '<caminho-de-configuração-do-arquivo-websocket>/websocket';

@Component({
    // conteúdo omitido
})
export class ExampleComponent implements OnInit {

    constructor(private wsActionRunnerService: WebSocketActionRunnerService) { }

    public ngOnInit(): void {

        // webSocketConfig objeto do tipo ***Config***
        this.wsActionRunnerService.connectConfig(websocketActionRunnerConfig);
    }
}
```
