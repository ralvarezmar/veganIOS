# ***Timezone*** of the server machines

> **❗ Information**
>
> This documentation originated from the resolution of the so-called [AFE-992](https://jira.santanderbr.corp/browse/AFE-992)

## Contextualization

The ***500 Internal Server Error*** error during requests to **APIs** on ***Apigee*** may be related to the ***Timezone*** of the server machines.

## Solution

To fix this, you must first align the issue with the [integration architecture team](https://confluence.santanderbr.corp/pages/viewpage.action?pageId=225764440) and then contact:

[PAAS support](https://confluence.santanderbr.corp/display/PAASDEVBR/Suporte+PaaS) to request this change in the **development**, **HK**, and **production** environments.
