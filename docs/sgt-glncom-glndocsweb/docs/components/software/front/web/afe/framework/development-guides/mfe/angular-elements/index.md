# Angular Elements

**Angular Elements** are Angular components packaged and transformed into **Custom Elements**, thus becoming **Web Components**. Components agnostic to any framework.

## Web Components

***Web Component*** is a set of specifications that allow you to create reusable custom elements to be used in your web applications.

A Web Component is basically composed of these three technologies:

- **Templates**: Code snippets that are inactive until they are added to the page, where they run automatically.
- **Custom Elements**: allows you to define custom elements and their respective behaviors, thus creating your own ***tag*** ***HTML*** **custom**;
- **Shadow DOM**: allows the encapsulation and omission of its code by the browser, that is, it is mounted under the covers, not being visible by the normal ***DOM*** code;
