# Services Workers and Progressive Web App (PWA)

Also called ***PWA***, ***Progressive Web App*** is a development methodology, which makes the user experience similar to native apps on computers and mobile devices. Created using common web technologies, including ***HTML***, ***CSS***, and ***JavaScript***.

With the ability to run offline, PWA on mobile devices can perform much faster and provide more features, while also being portable on both desktop and mobile platforms.
