# How to update the architecture structuring

As Angular and its ecosystem evolve, AFE's structuring features are updated according to need and some of these updates end up causing *breaking* changes to projects.

Below you will find the structuring of the architecture with updates available for **version 10 of Angular**:

| Structuring | Documentation |
| ------------ | ------------ |
| **@afe/base-geral** Discontinued | [Migration from @afe/general base](https://confluence.santanderbr.corp/pages/viewpage.action?pageId=257649781) |
| **@afe/cli** | [@afe/cli update](https://confluence.santanderbr.corp/pages/viewpage.action?pageId=257647901) |
| **@afe/http-interceptors** | [@afe/http-interceptors update](./http-interceptors/index.md) |
| **@afe/encryption** | [@afe/encryption update](./encryption/index.md) |

> What are breaking changes?
>
> These are changes in parts of a piece of software that can cause failures in other components.
