# Obsolescence policy

Although Angular has a biannual update cycle, we decided not to strictly follow this calendar and **we carry out this update annually**.

With this, we stay up to date with the framework without causing major problems for the applications available in the organization.

**Front-End Architecture** has a plan to actively check changes to the ***framework*** and anticipate them to bring a less traumatic process to internal applications.

We start testing versions as soon as they are made available, but we only make them available after they are in a stable state, LTS (Long Term Support).

In other words, we started to approve the version only after its first six months of launch.

In this way, **we make these versions available at the end of each year**.

Therefore, this update is available during the ***freezing*** period.

> For more information, see the documentation on [Angular Life Cycle](./angular-lifecycle.md).
