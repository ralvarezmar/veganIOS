# Configuration of ***Headers***

## Reason

One of the reasons why **authorization errors** occur during coexistence is due to the lack of configuration of the necessary ***Headers***.

## Solution

In this case, it is necessary to [open a ticket to the CDG team](https://jira.santanderbr.corp/projects/SCDGHUBBR/), requesting the configuration of the ***Headers*** described in the documentation:

[how to configure the headers for coexistence between zup and apigee](https://confluence.santanderbr.corp/pages/viewpage.action?pageId=328927634).
