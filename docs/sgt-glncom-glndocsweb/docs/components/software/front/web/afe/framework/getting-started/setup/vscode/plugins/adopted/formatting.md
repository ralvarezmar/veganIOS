# Formatting

Most of the time we write code that is misaligned with the rest of the code. To fix this, we need to go back and fix the indentation on each line. In addition, we need to ensure that square brackets and tags are properly formatted in a readable format.

This process can quickly become tedious.

Luckily, we have extensions that can do the job for us.

**Important:** The [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) and [Beautify](https://marketplace.visualstudio.com/items?itemName=HookyQR.beautify) extensions cannot be active at the same time.

## [Prettier - Code formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)

**License:** MIT

This is the most popular extension that supports ***JavaScript***, ***TypeScript*** and ***CSS*** formatting using [**Prettier**](https://github.com/prettier/prettier).

**Usage Example:**

- ***JavaScript***, ***TypeScript***, ***Flow***, ***JSX***, ***JSON***
- ***CSS***, ***SCSS***, ***Less***
- ***HTML***, ***Vue***, ***Angular***
- ***GraphQL***, ***Markdown***, ***YAML***
- [What's your favorite language?](https://prettier.io/docs/en/plugins.html)
