# Authentication

The first step for an application to consume services in the Santander environment is to authenticate to the Services Hub.

Because of this, we have prepared the following tutorials teaching the most common forms of authentication using the architecture libraries and ***Angular*** for communication with the API Gateway used in Santander.

> Apigee is currently the API Gateway in use.

- [Referral authentication in the coexistence login between ***Zup*** and ***Apigee***](./zup-apigee/index.md)
