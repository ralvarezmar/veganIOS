# Git Flow for libraries

This tutorial is intended to serve as a practical guide to teach Git Flow best practices in the context of libraries published on artifactory.

The first step is to define which operating model best fits the project from the following alternatives.

- [Full Template](./full-template/index.md): Runs deliverables so that each new release contains more than one change or urgent deliverables;
- [Simplified Template](./simplified-template/index.md): Performs the fastest value deliveries without the need to accumulate changes.

> **⚠️ Note**
>
> The alternatives are just suggestions, and if none of them meets the needs of the project, it is possible to base them on them to create an operating model that best suits the team.
