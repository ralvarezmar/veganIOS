# Command for semantic versioning

Through the ***standard-version***, which is a library for versioning following [SemVer](https://semver.org/) and ***CHANGELOG*** generation if we follow [Conventional Commits](https://conventionalcommits.org).

This command performs some important steps in the development flow

> **Note**
>
> In order to have the correct functioning of versioning and updating versions, the initial version of the project before running the ***release*** command must be ***1.0.0*** or greater.
>
> It is not recommended to run the controller with the ***major*** version of the project at 0 (e.g. ***0.0.0***)
