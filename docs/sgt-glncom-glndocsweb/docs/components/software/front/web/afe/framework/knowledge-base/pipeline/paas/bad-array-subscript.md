# How to troubleshoot "***tokens[$key]: bad array subscript***"

When performing ***deploy*** of a SPA application, the error **tokens[$key]: bad array subscript** may be displayed during the execution of the treadmill.

## Contextualization

The problem is generated by the ***script*** responsible for overriding the project variables, when there is an absence of a line break at the end of the ***replace.tokens*** file.

## Solution

To resolve the issue, add a line break at the end of the ***replace.tokens*** file, to ensure that the lines are read correctly.
