# HTTP Interceptors

***@afe/http-interceptors*** is a library with interceptor modules for various requests within the flow of an application.

The piece is composed of ***interceptors*** for ***HttpClient*** from ***@angular/common/http*** and aims to facilitate the development of front-end applications in the bank's environment.

## Compatibility

Using the table below and based on the **version of Angular in your project**, follow the steps described in the documentation for **installation** and **configuration** from the part version.

| Angular Version | Part Version |
| ---------------- | ---------------- |
