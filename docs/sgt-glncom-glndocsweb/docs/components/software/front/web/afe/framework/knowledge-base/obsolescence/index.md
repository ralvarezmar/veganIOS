# **Obsolescence** Knowledge Base

This session is intended to provide a path to guide projects to solve problems related to updating their front-end applications.

## 🎯 Overview

Errors related to obsolescence can happen by:

- Third-party dependencies that have not been updated after the project was updated;
- Problems at the time of executing the update command due to local environment issues;

## 📋 Initial Checklist

Before proceeding to the mapped scenarios that we have documented, follow the checklist to do a recap of the procedure required for using external libraries and dependencies:

- Be sure to update the project in stages, so that you can catch the mistakes little by little and not accumulate to the end;
