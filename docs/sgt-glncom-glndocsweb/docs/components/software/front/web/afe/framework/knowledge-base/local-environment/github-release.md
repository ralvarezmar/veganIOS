# How do I grant access to GitHub?

## Contextualization

For the use of GitHub, the risk of sending code to the public GitHub was mapped, and an approval of the new configuration was made on the proxy servers, with the main objective of blocking the upload.

## Solution

Request access through the Access Space -> Access Group -> ***GSEG_Proxy_GITHUB***, after this request is made an analysis of the reason by the security area, the approval of the user manager will also be required.
