# Differences Between Monolithic SPA and MFE

| Monolithic SPA | Micro Front-End |
| --- | --- |
| Monolithic Application | Self-contained application with independent life cycle |
| Low scalability | High scalability |
| All modules are loaded into a single ***bundle*** | Modules are loaded as needed |
| Single Development Flow | Reuse of modules in different applications;
 | App Update Requires Full Regression Testing | Isolated maintenance and upgrading. |
