# Front-end Architecture Libraries

The Front-End Architecture libraries provide support and standardization to developers to facilitate the development of web applications on F1rst.

| Library | Objective |
| --------------- | -------- |
| [***@afe/authentication***](./afe/authentication/index.md) | Orchestrate user authentication in the application. |
| [***@afe/authorization-manager***](./afe/authorization-manager/index.md) | Connect an application to authentication services across multiple data sources |
| [***@afe/cli***](./afe/cli/index.md) | Initializes, updates, and maintains Angular projects according to the standard set by the front-end architecture team. |
| [***@afe/context-handler***](./afe/context-handler/index.md) | **Manage context data** from **session** or **workspace** |
| [***@afe/devkit-angular***](./afe/devkit-angular/index.md) | **Abstract configurations and processes** from **'build'** and **related** proposed by AFE. |
| [***@afe/elements***](./afe/elements/index.md) | **Assist in the development of self-contained applications** of the micro front-end architecture proposed by AFE |
| [***@afe/encryption***](./afe/encryption/index.md) | **Handle the encryption of the data** that will be trafficked by the application |
| [***@afe/dlb-sdk***](./afe/dlb-sdk.md) | **Abstracts the encryption script** developed by the Security Solutions |
| [***@afe/event-handler***](./afe/event-handler.md) | **Log and fire events** purely in javascript |
| [***@afe/eslint-plugin-devkit-lint***](./afe/eslint-plugin-devkit-lint/index.md) | **Lint Rules** using ESLint for JavaScript and TypeScript |
| [***@afe/http-interceptors***](./afe/http-interceptors/index.md) | **Intercept miscellaneous requests** within the flow of an application in the Santander environment |
| [***@afe/pipes***](./afe/pipes/index.md) | **Format and display data** correctly |
| [***@afe/tagging***](./afe/tagging/index.md) | **tag** projects in the Santander environment |
| [***@afe/websocket-action-runner***](./afe/websocket-action-runner/index.md) | **Encapsulate** **WebSocket** technology and provide a configuration and functionality facilitator |
