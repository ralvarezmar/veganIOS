# Android

Gluon will offer Android/Kotlin ODS framework as its reference framework for Android.

This framework is globally used by ODS applications. Now, powered by Gluon, every entity will be capable of using it and, furthermore, being able to reuse all the technical and functional components it is already developed over it.

You can take a look at the [key principals](https://ideal-doodle-rr76vg6.pages.github.io/android/architecture-overview/clean-architecture/) of the framework in the ODS Documentarion.

The main libraries of the Android framework is ok-android-commons. If you are interested on take a look at its API, you'll find it [here](https://ideal-doodle-rr76vg6.pages.github.io/android/libraries/ok-android-commons-docs/).

Regarding the creation of the different types of components, we are working hard to provide this two kinds from the Gluon Portal:

- Android Libraries: That will help you to create functional libraries, ODS refers to them as [Products or L1's](https://ideal-doodle-rr76vg6.pages.github.io/android/architecture-overview/functional-layer/).
If you want to start creating this type of component, you'll find anything you need to know in the [Android Library Journey](../lib.md).

- Android App: This kind of component is not ready to be used yet from the Gluon Portal, stay tuned for next info.
