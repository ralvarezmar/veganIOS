## API Deployment Governance

Before starting the deployment process, local API Architect has to clearly define the version of the API which will be deployed, the entity application, and the correct exposure (e.g. Internet, intranet,...)

With this information the Local Entity API Portfolio Manager accepts or rejects the deployment proposal. In case it is approved, the deployment repository is created.

Currently, the ways to deploy an API is using the [**API Deployment 2.0**](../../../../../architecture/tech-stack/snippets/apis/apis.md) and [**API Product**](../../products.md) components (Recommended).
