### Global Head Of APIs

- Defines and refines API Strategy and Governance Model, reporting to Global CTO.
- Coordinates Local Head of APIs, which report to this role.
- Identification of API Governance requirements for Gluon and roadmap evolution coordination with Gluon team.
- Manages Global API Portfolio, deciding on API proposals raised by Local Governance, and promoting verified API definitions to Global Catalog under a declared SLA.
- Oversights API Strategy execution across Santander Group.

### Local Head Of APIs

- Manages entity API Portfolio (decides which APIs must be added/updated/retired) according to Global API Strategy.
- Centralizes all API Demands in the entity.
- Leads all API Designers in the entity, regardless of the areas/domains the organizationally belong to.
- Promotes API Definition proposals to Global Governance.
- Authorizes deployment of new APIs in the entity.

### API Designer

- Highly specialized role, with expertise in API architecture.
- Reports to Local API Architect.
- Engages with Solution Design Architects, project teams, security architects  and functional experts to refine API demand so that it can be properly evaluated.
- Executes approved API Definitions, engaging with BaaS Terms Dictionary team to complete API Definition.
- Guarantees that API Definitions comply with Global API Normative.
