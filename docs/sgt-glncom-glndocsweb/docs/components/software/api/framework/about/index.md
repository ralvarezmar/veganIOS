## We want Santander to become a true API oriented company. <br>

A **Santander Group API** is an interface exposed by a system to establish a technical and functional form of interaction with multiple systems. It is a contract and an access road that allows interoperability between systems.

- **A single API layer with the same definitions across the Group** to foster business composability and speed up global products deployment, and local/global implementations depending on the back-end.

- **Product Oriented APIs**, not project oriented, removing redundancies and clutter to improve API discovery experience for developers.

- **Common way to define, develop, publish and consume APIs** to improve developer experience, time to market and quality.

- **Single E2E API Platform** to facilitate governance and maximize technical and infrastructure efficiency.
