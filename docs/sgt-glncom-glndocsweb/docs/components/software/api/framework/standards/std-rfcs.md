## ​RFCs / W3C Standards

### Data Type Recommended Formats

1. [RFC 3339](#rfc-3339) for date / time formats.
2. [ISO 20022](https://www.iso20022.org/)
3. [ISO 3166-1](#iso-3166-1) alpha2 country codes.
4. [ISO 639-1](#iso-639-1) language code.
5. [BCP-47](#iso-639-1) (based on [ISO 639-1](#iso-639-1)) for language variants.
6. [ISO 4217](#iso-4217) currency codes.
7. integer \> int32 \> integer between -231 and 230.
8. integer \> int64 \> integer between -263 and 262.
9. integer \> bigint \> arbitrarily large signed integer number.
10. number \> float \> [IEEE 754-2008/ISO 60559:2011](#iso-605592020) binary64 decimal number.
11. number \> double \> [IEEE 754-2008/ISO 60559:2011](#iso-605592020) binary128 decimal number.
12. number \> decimal \> arbitrarily precise signed decimal number.
13. Descriptions data documented must be aligned with examples documented in swagger and returned in Echo or sandbox API implementation
