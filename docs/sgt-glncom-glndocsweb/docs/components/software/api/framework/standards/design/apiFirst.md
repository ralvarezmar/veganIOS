# API First

### **API Standard**

Santander Group API Design **MUST be API First**

### **Guidelines**

- Development of an API MUST always start with API design without any upfront coding activities.
- API design is the master of truth, not the API implementation.
- API consumers MUST NOT assume or rely on any knowledge of the API service internal implementation.
- APIs MUST be designed consistently with the guidelines defined in this document.
- The API implementation MUST always conform to the specific API design, which is essentially the agreement between the API and its consumers.
- API design MUST be done in OpenAPI Specification 3.x format.
