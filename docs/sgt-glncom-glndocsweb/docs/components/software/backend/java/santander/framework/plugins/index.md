# Santander Spring Boot Plugins

## Gluon Partenon Maven-Plugin

Gluon Java Partenon Maven-Plugin is a code generator that creates all necessary sources (a service and request/response transaction POJOs)
from configuration to call Partenon transactions in a Santander Spring Boot microservice.

Find the documentation here: [Gluon Partenon Maven-Plugin](./partenon-plugin.md)
