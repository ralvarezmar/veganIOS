# Apache Tomcat

Apache Tomcat is a open source servlet container used for serving Java web
applications. It's one of the most used Java servlet container.

## What's a servlet container?

A servlet container, or web container, is a component of web server that manages
Java servlets. Java servlets are Java classes that handle HTTP requests. In
other words, when an application that runs in a web server receives a request,
it passes the request to the service container, which allocate it to a servlet.

For more details, check the [Tomcat homepage](https://tomcat.apache.org/).
