# Arsenal Integration 3.8.x to 4.x.x Migration Guide

This guide is intended to show the migration of an application generated by the
archetype Arsenal Integration, version 3.8.x to an Arsenal Gluon Integration
application, version 4.x.x. In this migration, several upgrades and improvements
were made, including the use of Spring 3 and Camel 4.

## Update pom.xml

### update parent

First we need to update the parent version:

``` xml
<parent>
    <groupId>com.santander.ars</groupId>
    <artifactId>gln-back-arsenal-integration-lib-parent</artifactId>
    <version>4.x.x</version>
</parent>
```

### update properties

Some properties should be added and the properties that are no longer being used should be removed:

Change **generator.filePath** tag to **openapi-contract-path**:

``` xml
<openapi-contract-path>${basedir}/src/main/resources/swagger/swagger.yaml</openapi-contract-path>
```

Add or update properties below:

``` xml
<springdoc-openapi-starter-webmvc-ui.version>2.1.0</springdoc-openapi-starter-webmvc-ui.version>
<openapi-generator-maven-plugin.version>6.3.0</openapi-generator-maven-plugin.version>
<jacoco-maven-plugin.version>0.8.8</jacoco-maven-plugin.version>
```

Remove java version tag:

``` xml
<java.version>17</java.version>
```

### update dependencies

Old arsenal libraries should be removed and the starters used in Gluon
should be used instead.

Add to **dependencyManagement** tag:

``` xml
<dependencies>
    <!-- Spring Boot BOM -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-dependencies</artifactId>
        <version>${spring-boot.version}</version>
        <type>pom</type>
        <scope>import</scope>
    </dependency>
    <!-- Camel Spring Boot BOM -->
    <dependency>
        <groupId>org.apache.camel.springboot</groupId>
        <artifactId>camel-spring-boot-bom</artifactId>
        <version>${apache-camel.version}</version>
        <type>pom</type>
        <scope>import</scope>
    </dependency>
    <!-- Camel BOM -->
    <dependency>
        <groupId>org.apache.camel</groupId>
        <artifactId>camel-bom</artifactId>
        <version>${apache-camel.version}</version>
        <type>pom</type>
        <scope>import</scope>
    </dependency>
</dependencies>
```

* log4j-api
* log4j-to-slf4j
* integration-starter-web
* integration-starter-test
* arsenal-security-starter
* camel-http

### update plugins

Some plugins should be added or removed in the new version:

In the **build** tag:

Remove from **pluginManagement** tag:

lifecycle-mapping

Remove from **plugins** tag:

swagger2camel-maven-plugin
swagger-codegen-maven-plugin

Update spring-boot-maven-plugin to:

``` xml
<plugin>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-maven-plugin</artifactId>
    <version>${spring-boot.version}</version>
    <executions>
        <execution>
            <goals>
                <goal>repackage</goal>
            </goals>
        </execution>
    </executions>
</plugin>
```

Add the following plugins to **plugins** tag:

``` xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <version>${maven-compiler-plugin.version}</version>
</plugin>
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-surefire-plugin</artifactId>
    <version>${surefire-plugin.version}</version>

<plugin>
    <groupId>com.santander.ars</groupId>
    <artifactId>gln-back-arsenal-integration-openapi-maven-plugin</artifactId>
    <executions>
        <execution>
            <phase>generate-sources</phase>

                <goal>generator</goal>
            </goals>
            <configuration>
                <fileSwaggerYamlJsonLocation>${openapi-contract-path}</fileSwaggerYamlJsonLocation>

                <isGluon>false</isGluon>
                <skip>false</skip>
                <skipOverwrite>true</skipOverwrite>

    </executions>
</plugin>
<plugin>
    <groupId>org.openapitools</groupId>
    <artifactId>openapi-generator-maven-plugin</artifactId>
    <version>${openapi-generator-maven-plugin.version}</version>
    <executions>
        <execution>
            <goals>
                <goal>generate</goal>
            </goals>
            <configuration>
                <inputSpec>${openapi-contract-path}</inputSpec>
                <generatorName>spring</generatorName>
                <modelPackage>GROUPID.model.dto</modelPackage>
                <generateModels>true</generateModels>
                <generateSupportingFiles>false</generateSupportingFiles>
                <generateSupportingFiles>false</generateSupportingFiles>
                <generateModelTests>false</generateModelTests>
                <generateModelDocumentation>false</generateModelDocumentation>
                <generateApis>false</generateApis>
                <generateApiTests>false</generateApiTests>
                <generateApiDocumentation>false</generateApiDocumentation>
                <configOptions>
                    <dateLibrary>java8</dateLibrary>
                    <useBeanValidation>false</useBeanValidation>
                    <openApiNullable>false</openApiNullable>
                    <useJakartaEe>true</useJakartaEe>
                </configOptions>
            </configuration>
        </execution>
    </executions>

<!-- END CONFIGURATION OF THE PLUGIN TO GENERATE CAMEL CODE BASED ON SWAGGER.YAML -->
<!-- jacoco plugin to generate the report to sonar -->
<plugin>
    <groupId>org.jacoco</groupId>
    <artifactId>jacoco-maven-plugin</artifactId>
    <version>${jacoco-maven-plugin.version}</version>
    <executions>
        <execution>
            <phase>test-compile</phase>
            <id>default-prepare-agent</id>
            <goals>
                <goal>prepare-agent</goal>
            </goals>

        <execution>
            <phase>test</phase>
            <id>default-report</id>

```

**IMPORTANT**
Change **rootPackageClass** and **modelPackage** to use the project groupId

## Update Classes

Remove the annotations **@EnableIntegrationCore**, **@EnableArsenalSecurity** and any **@Enable...** of
Arsenal dependencies from **IntegrationApplication**. They are no longer needed in the new version.

Add **@OpenAPIDefinition** annotation to **IntegrationApplication** to make SwaggerUI work correctly:

``` java
@OpenAPIDefinition(
        servers = {
                @Server(url = "${openapi.server.path}")
        }
)
```

Remove the **SwaggerController** file that isn't needed anymore.

## Update Application Properties

Add **openapi.server.url** property with the same value of camel context path without the **/*** suffix.
This property is used by **@OpenAPIDefinition** to make SwaggerUI work correctly.

Example:

``` yaml
camel:
    servlet:
        mapping:
            contextPath: /party/v1/*

openapi:
    server:
        path: /party/v1
```

## Tips

* Use [Swagger Editor](https://editor.swagger.io/) to update specification to OpenAPI 3 if necessary.

* Delete unused properties and dependencies when finished the migration.

* Api doc will be available at \[HOST\]:\[PORT\]/\[SPRING-MVC-SERVLET-PATH\]/v3/api-docs

* Swagger UI will be available at: \[HOST\]:\[PORT\]/\[SPRING-MVC-SERVLET-PATH\]/\[SPRING-MVC-SERVLET-PATH\]/swagger-ui/index.html
