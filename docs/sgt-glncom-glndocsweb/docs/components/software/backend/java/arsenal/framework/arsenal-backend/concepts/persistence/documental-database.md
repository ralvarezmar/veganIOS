# Documental database

Document database or document-oriented database is a term that has become
increasingly popular in the community for implementing the concept of NoSQL.

When we consider using a NoSQL database, consequently we are focusing on
BigData, as characteristics such as dynamic schema (or lack thereof), high
performance and flexibility are stronger than an SQL database.

Currently, there are N types of tools that implement the NoSQL concept:

* Columns (HBase, Cassandra)
* Graph (Neo4j)
* Key-Value (REDIS and MemcacheD)
* Document (MongoDB)

For this guide, we will use MongoDB, a schema-free document database (or dynamic
schema), capable of grouping all information in a single document, has advanced
MapReduce means, in addition to allowing redundancy.
