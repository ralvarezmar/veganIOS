# Arsenal Integration Framework Libraries and Starters

This document provides a comprehensive list of all the starters and libraries used in the project, along with a brief description of their responsibilities. These components are essential for configuring and
implementing various functionalities within the application.

| Starter/Lib                                                                                                  | Description                                                                                                                                                                                                                                                                                                                                                                    |
|--------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [arsenal-integration-altair-connector](how-to-guides/integration/altair.md)                                  | Provides integration capabilities with the Altair system, enabling seamless communication and data exchange between the application and Altair. This connector ensures that data is correctly formatted and transmitted, allowing for efficient interaction with Altair services.                                                                                              |
| arsenal-integration-custom-method-starter                                                                    | Implements custom methods in Apache Camel Servlet, allowing for the extension and customization of Camel routes and processors. This starter provides the necessary infrastructure to define and execute custom business logic within Camel routes.                                                                                                                            |
| [arsenal-integration-embeddedcrypto](how-to-guides/security/embedded-crypto.md)                              | Offers embedded cryptographic functionalities, including encryption, decryption, and secure key management, to ensure data security within the application. It provides a set of tools and APIs to handle cryptographic operations seamlessly.                                                                                                                                 |
| arsenal-integration-error-starter                                                                            | Provides error handling and management capabilities, including custom error responses and logging, to improve the robustness and reliability of the application. This starter helps in capturing, logging, and responding to errors in a consistent manner.                                                                                                                    |
| arsenal-integration-legacy-connector                                                                         | Facilitates integration with legacy systems, enabling the application to communicate with and leverage existing legacy infrastructure and services. It ensures compatibility and smooth data exchange with older systems that are still in use.                                                                                                                                |
| [arsenal-integration-observability-starter](how-to-guides/observability/observability.md)                    | Enhances the observability of the application by providing tools and configurations for monitoring, logging, and tracing, helping to ensure the application's performance and reliability. This starter integrates with various observability platforms to provide insights into application behavior.                                                                         |
| arsenal-integration-openapi-client-maven-plugin                                                              | Generates client code from OpenAPI specifications, simplifying the process of creating and maintaining API clients based on OpenAPI definitions. This plugin automates the generation of client-side code, ensuring consistency and reducing manual coding efforts.                                                                                                            |
| [arsenal-integration-openapi-maven-plugin](tutorials/integration-openapi-maven-plugin.md)                    | Provides tools for generating OpenAPI specifications from existing code, facilitating the creation and maintenance of API documentation and client code. This plugin helps in documenting APIs and generating OpenAPI specs directly from the codebase.                                                                                                                        |
| [arsenal-integration-security-channel-holder-starter](how-to-guides/security/web-security-channel-holder.md) | A starter was created to automatically extract the information of the channel from a JWT claim named `channel_tp`, and set its value in the camel message header `X-appname`, when an application that exposes REST resources received a request.                                                                                                                              |
| arsenal-integration-tracing-starter                                                                          | Adds distributed tracing capabilities to the application, allowing for the tracking of requests across different services and components, which helps in diagnosing issues and understanding system behavior. This starter integrates with tracing systems to provide end-to-end visibility of request flows.                                                                  |
| [arsenal-integration-archunit-plugin](archunit-rules.md)                                                     | Provides integration with ArchUnit, a library for checking the architecture of Java code. This plugin allows you to define and enforce architectural rules within your project, ensuring that the codebase adheres to specified design principles and patterns. It helps in maintaining a clean and well-structured architecture by enabling automated checks and validations. |
