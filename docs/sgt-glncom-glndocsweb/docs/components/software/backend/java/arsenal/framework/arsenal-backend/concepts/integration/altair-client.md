# Altair Client

## Altair Client Starter

The most common scenario for using the library will be in mainframe calls.
Microservices need to be able to know the transaction they are going to execute,
the respective data of the transaction, the format that the transaction
receives, which can be: PS7, PS8 and TFC.

To see a usage of Altair Client Starter [click
here](../../how-to-guides/integration/use-altair-client.md).
