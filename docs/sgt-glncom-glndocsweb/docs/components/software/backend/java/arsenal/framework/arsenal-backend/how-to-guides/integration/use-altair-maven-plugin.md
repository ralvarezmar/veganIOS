# Using Altair Code Generator Maven Plugin

Altair Code Generator Maven is a code generator project that translates Copy Book metadata into Java classes.
Additionally, it generates configured and ready-to-use Altair clients for each *transaction code*,  responsible for sending personified and non-personified messages to Altair.

## Prerequisites

To compile and run the generated code you will need:

- JDK 17+
- Lombok 1.28+
- Spring Framework 6+
- `com.santander.ars:gln-back-arsenal-backend-embeddedmainframe` dependency
- `com.santander.ars:gln-back-arsenal-backend-web-channel-holder-starter` dependency
- One or more *transaction code* json files with copy book format metadata generated by [`CLI Altair Code Generator`](use-altair-cli-code-generator.md)

## Limitations

- If any Copy Book field data type has not been mapped, it will be generated as the Java `Object` data type.

## Installation

Arsenal Gluon Altair Code Generator is a maven plugin. To use it, just declare it in your pom.xml file:

```xml
<plugin>
    <groupId>com.santander.ars</groupId>
    <artifactId>gln-back-arsenal-altair-codegen-maven-plugin</artifactId>
    <version>${revision}</version>
    <executions>
        <execution>
            <phase>generate-sources</phase>
            <goals>
                <goal>generate</goal>
            </goals>
        </execution>
    </executions>
    <configuration>
        // copybooks path that was created using cli mentioned above
        <copyBookFilePaths>
            <copyBookFilePath>/path/to/copybooks/transactionCode1.json</copyBookFilePath>
            <copyBookFilePath>/path/to/copybooks/transactionCode2.json</copyBookFilePath>
        </copyBookFilePaths>
        // package where will be created model classes
        <modelsPackage>com.santander.package.mymodels</modelsPackage>
        // package where will be created client service classes
        <altairServicesPackage>com.santander.package.myclients</altairServicesPackage>
        // option to replace the files every time the plugin is run
        <fileOverride>false</fileOverride>
    </configuration>
</plugin>
```

After that, you can execute the `generate-sources` maven lifecycle to generate the source code:

```bash
mvn genenate-sources
```

The source code will be generated within the `src/main/java` directory, and test code in `src/test/java` by default.
You will be able to make the necessary adjustments and customizations in your Copy Book models, Altair client and tests.

The plugin is responsible for generating the following:

- Models for all Copy Book Formats specified in the json file with Altec annotations `@PsFormat`, `@PsFieldNumber` and so on.
- `AltairClientServices` for each transaction codes, capable of sending personified and non-personified messages for Altair.
- `AltairClientServiceHelper` component with some auxiliary functions and properties to handle with Altair inputs and outputs.
- Unit tests for each model, client and helper, using JUnit.
