# Darwin Plugins

## Gluon Darwin Code Analysis Maven-Plugin

Gluon Darwin Code Analysis Maven-Plugin is a code analysis tool that uses the ArchUnit library to check the code quality of a project.

Find the documentation here: [Gluon Darwin Code Analysis Maven-Plugin](./codeanalysis-plugin.md)

## Gluon Partenon Maven-Plugin

Gluon Java Partenon Maven-Plugin is a code generator that creates all necessary sources (a service and request/response transaction POJOs)
from configuration to call Partenon transactions in a Darwin microservice.

Find the documentation here: [Gluon Partenon Maven-Plugin](./partenon-plugin.md)

## Arsenal JPA Code Generator

Arsenal JPA Code Generator is a code generator project that parses DDL (Data Definition Language) commands from SQL (Structured Query Language) and translates them into JPA Java classes.
Furthermore, it generates the repository layer for each entity that meets the JPA specification for relational databases.
This plugin is entirely compatible with Darwin Spring Boot.

Find the documentation here: [Arsenal JPA Code Generator](../../../arsenal/framework/arsenal-backend/tutorials/code-generator-jpa-maven-plugin.md)
