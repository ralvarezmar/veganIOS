## 2.7.0-RELEASE Version

<!tag:270>

- A totally new archetype of libraries is created along the lines defined by the GoCloud initiative:

    - A project is generated with an auto-configuration class, a properties configuration class and a component to expose as a Bean. Tests are added to all these classes.

    - The archetype parameters are defined according to the GoCloud initiative: *component-name* and *acronym-app*.

    - The archetype should only be used in *Batch* mode to ensure its correct operation.

<!end:270>
