# Ready-to-use Archetypes

Archetypes is a Maven feature that provides us with reusable and tested code.
It's a faster way to skip that repetitive tasks you always have to do at the beginning of a new application development lifecycle.
With the archetypes you can focus directly on your business logic.

Take a look at these samples we've developed for you:

* [Imperative ORM](photon-quarkus-archetype-orm/README.md)—The simplest archetype plus Object Relational Mapping features.
* [Extension Library](photon-quarkus-archetype-extension/README.md)—How to extend Photon capacity creating your own library

You can find detailed information about every archetype following this list of README Files.

## Archetypes

You can start your new application from scratch, or you can take advantage of the Architecture Team's experience using the archetypes.

### What are Archetypes?

According to Maven Archetype page,
"In short, Archetype is a Maven project templating toolkit.
An archetype is defined as an original pattern or model from which all other things of the same kind are made.
The name fits as we are trying to provide a system that provides a consistent means of generating Maven projects".
In even shorter, it's a generic template to well-known applications.

Consult this [Maven Archetype](https://maven.apache.org/guides/introduction/introduction-to-archetypes.html) article for more information.
