## What is Photon?

Photon is a framework for the creation of Cloud Native applications using Java,
and it is based on the Quarkus framework.
Its target is
to facilitate and speed up the development of applications designed for microservice-based architectures,
covering the cross-cutting aspects required by the organization.
These `cross-cutting` aspects are: security, observability, performance, and so on.
