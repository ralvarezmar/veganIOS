
# DATAGRID

## Summary

**RED HAT JBOSS DATA GRID** is a distributed and in-memory NoSQL data storage solution.
With it, your applications can access, process and analyze the data, which is stored in the main memory, to provide faster response times and a better user experience. It meets two major needs:

- Access to large volumes of data for use in real time.
- Performance and extension of the application.

Memory-resident data grids are an intelligent solution for both of these problems as:

- Ensure in-memory data availability through easy access. Data grids in-memory residents achieve extremely fast read/write performance.
- Automatically retain unused data in a file system or maintain memory-resident nodes to ensure high reliability and fault tolerance.
- Increase and reduce distributed nodes.
- Automatically distribute information across the cluster for grid growth as the needs for scale and performance change.

**DARWIN DATAGRID** It is a library that encapsulates all the functionalities that we find in [infinispan](https://www.npmjs.com/package/infinispan) since it is the official client for **RED HAT JBOSS DATA GRID**.

The extended documentation on its use and configuration can be found [here](https://confluence.ci.gsnet.corp/pages/viewpage.action?pageId=133926868)

!!! info "Important"
    This library has .d.ts declaration files so that it can be instantiated from typescript.

## How to use it

We have two ways to use it, either for Javascript or Typescript. We are going to put two examples of them.

### Javascript

```js
const { Client } = require('@darwin-node/datagrid');
const options = {
  maxRetries: 1, // Maximum number of retries
  cacheName: 'test',
  version: '2.9'
};
const serverAddress = {
  port: 11222,
  host: '127.0.0.1'
};
const start = async () => {
  const client = await Client(serverAddress, options);
}
start();
```

We need to note that in order to be able to do a **await** we have to be within an asynchronous function.

!!! info "Important"
    For our local tests it is mandatory to set the topologyUpdates option to false, to avoid auto-discovery.

### Typescript

```js
import { Client, serverAddress, options } from '@darwin-node/datagrid';
let opts: options;
opts = {
  maxRetries: 1, // Maximum number of retries
  cacheName: 'test',
  version: '2.9'
};
let hosts: serverAddress
hosts = {
  port: 11222,
  host: '127.0.0.1'
};
const start = async () => {
  const client = await Client(hosts, opts);
}
start();
```

### Complete example of implementation

In this example we are going to include two new things that we did not include in the previous one:

- Error handler.
- Subscription to the events offered by the bookstore.

The example consists of creating a client, subscribing to the events generated by the server and a test with most of the operations that the library offers us.
The example is in pure Javascript, but it is extrapolated to typescript

```js
const { Client } = require('@darwin-node/datagrid');
const options = {
  maxRetries: 1, // Maximum number of retries
  cacheName: 'test',
  version: '2.9',
  topologyUpdates: false // This flag is for self-discovery
};
const serverAddress = {
  port: 11222,
  host: '127.0.0.1'
};
const addListeners = (client) => {
  client.addListener('create', (data) => {
    console.log('******** LISTENER ON Creating: ', data);
  });
  client.addListener('modify', (data) => {
    console.log('******** LISTENER ON modify: ', data);
  });
  client.addListener('remove', (data) => {
    console.log('******** LISTENER ON remove: ', data);
  });
  client.addListener('expiry', (data) => {
    console.log('******** LISTENER ON expiry: ', data);
  });
};
const start = async () => {
  let client;
  try {
    client = await Client(serverAddress, options);
    await client.ping();
    addListeners(client);
    // put
    console.log('adding key [key]');
    await client.put('key', { data: { value: 10 } });
    console.log(await client.get('key'));
    console.log('\n\n');
    // containsKey
    console.log(`constains [key] status: ${await client.containsKey('key')}`);
    console.log('\n\n');
    // get key
    console.log(`Getting [key]: ${await client.get('key')}`);
    console.log('\n\n');
    // getWithMetadata
    console.log(`getWithMetadata: ${JSON.stringify(await client.getWithMetadata('key'))}`);
    console.log('\n\n');
    // remove
    console.log('adding key test-key');
    await client.put('test-key', { data: 'i am a test data' });
    console.log(`Getting test-key: ${JSON.stringify(await client.get('test-key'))}`);
    console.log(`Removing test-key ${await client.remove('test-key')}`);
    console.log(`Trying to get removed key: ${await client.get('test-key')}`);
    console.log('\n\n');
    // putIfAbsent
    console.log(`Trying to add [key] but the key exists: ${await client.putIfAbsent('key', { data: 'fake data' })}`);
    console.log(`Trying to add [key-if-Absent] but the key exists: ${await client.putIfAbsent('key-if-absent', { data: 'fake data' })}`);
    console.log(`Getting [key-if-Absent]: ${await client.get('key-if-absent')}`);
    console.log(`Removing [key-if-Absent]: ${await client.remove('key-if-absent')}`);
    console.log('\n\n');
    // replace
    console.log('adding key replace-key to test [replace, replaceWithVersion, removeWithVersion]');
    await client.put('replace-key', { data: 'i am a replace key 1' });
    console.log(`Getting replace-key: ${JSON.stringify(await client.get('replace-key'))}`);
    console.log(`Replacing replace-key ${await client.replace('replace-key', { data: 'i am replaced 1 time' })}`);
    console.log(`Getting replace-key: ${JSON.stringify(await client.get('replace-key'))}`);
    console.log(`Removing replace-key: ${await client.remove('replace-key')}`);
  } catch (e) {
    console.error(e);
  } finally {
    await client.disconnect();
  }
};
start();
```

## Environment Variables

| Clave  | Campo | Valor (por defecto)  |
|---|---|---|
| process.env.DARWIN_DATAGRID_HOT_ROD_PROTOCOL_VERSION | version |  '2.9' |
| process.env.DARWIN_DATAGRID_CACHE_NAME | cacheName | undefined|
| process.env.DARWIN_DATAGRID_MAX_RETRIES | maxRetries | 3|
| process.env.DARWIN_DATAGRID_DATAFORMAT_KEY_TYPE | dataFormat.keyType | 'application/json'|
| process.env.DARWIN_DATAGRID_DATAFORMAT_VALUE_TYPE | dataFormat.valueType | 'application/json'|
| process.env.DARWIN_DATAGRID_DATAFORMAT_TOPOLOGY_UPDATES | topologyUpdates | false|
| process.env.DARWIN_DATAGRID_CLUSTERS | clusters | []|

> Possible version values can be 2.9, 2.5, and 2.2
