## Introduction

The purpose of this documentation is to provide the technical information needed to deploy a Encryption Manager resource in AWS and/or AZ provider.

## Services Deployed by the component

|Service|Description|
|-------|-----------|
|[AWS Key Management Service](./aws.md)| AWS Key Management Service (AWS KMS) lets you create, manage, and control cryptographic keys across your applications and AWS services.|
|[Azure Key Vault](./az.md)| Azure Key Vault is a cloud service for securely storing and accessing secrets. |
