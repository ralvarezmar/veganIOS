### Running the microservice
<!-- Start Running Microservice -->
To Run the microservice, first you will have to install the dependencies. To do so, run the following command:

```bash
npm install
```

After that, you can run the microservice with:

```bash
npm run start
```

If the microservice is in typescript, the previous command will fail unless the following command is executed:

```bash
npm run build
```
