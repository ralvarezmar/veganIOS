### What's Changing?

- A fix has been implemented to resolve the issue where filtering releases by the date field caused an error.
 The filtering functionality now works correctly, displaying only the releases that match the selected date and restricting access to releases outside the user's application and company.

### Why Is This Important?

- This fix ensures that users can accurately filter releases by date, improving usability and efficiency.
 It also enforces proper access control, preventing users from viewing or interacting with releases from other applications or companies, thereby maintaining data security and compliance.
