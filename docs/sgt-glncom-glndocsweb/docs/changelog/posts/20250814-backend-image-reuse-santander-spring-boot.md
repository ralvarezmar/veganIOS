### What's Changing?

We are excited to announce that Santander Spring Boot microservices can now be reused through the Image Reuse Component in Gluon.

### Why Is This Important?

This enhancement enables applications to reuse microservice images generated with the Santander Spring Boot framework within Gluon applications.
By incorporating this feature, users can leverage the robust capabilities of Santander's Spring Boot microservices, increasing the variety of components that can be reused.

### How to Use This Feature?

When creating an Image Reuse component, you can now select the Santander Spring Boot Backend from the available options in the component `Image type` parameter.

For detailed implementation guidance, refer to the [Image Reuse documentation](../../components/configuration/kubernetes/image-reuse.md).
