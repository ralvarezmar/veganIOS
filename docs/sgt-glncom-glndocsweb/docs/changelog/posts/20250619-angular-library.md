We are excited to announce that, starting today, **our users can now create and manage Angular libraries using the official Angular CLI within the GLUON platform**.

This new feature enables teams to build, analyze, and publish reusable Angular libraries, following the same standards and practices as official Angular projects.
All monorepository management is handled through Angular CLI and `angular.json`, ensuring consistency and maintainability across your workspace.

### Why is this important?

Angular libraries are essential for sharing components, services, and utilities across multiple applications and teams.
By leveraging the Angular CLI, you benefit from a standardized workflow, improved developer experience, and seamless integration with the GLUON CI/CD pipelines.

### How to Use This Feature?

To get started, simply create a new component of type **Angular Library** from the Gluon Portal. The platform will scaffold the library structure using Angular CLI, including a playground application for development and testing.

You can then follow our step-by-step guide to build, analyze, and publish your library through the CI/CD process.

For detailed instructions and best practices, please refer to the [Angular Library Journey documentation](../../components/software/front/web/angular/library.md).
