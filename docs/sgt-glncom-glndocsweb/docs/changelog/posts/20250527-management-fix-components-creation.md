Enhancements have been made to the component creation process, improving integrations with Gluon tools and efficiently managing retries during the creation process to avoid errors and improve user experience.

### What's Changing?

- The configuration for handling retries during component creation has been optimized, enabling more efficient management and smoother integration with Gluon SDLC tools (Github, Sonarqube, Fortify, etc.).

### Why Is This Important?

This improvement ensures that the component creation process is more robust and reliable, reducing errors and enhancing the user experience when interacting
with the system. It also addresses issues related to response times and resolves 504 errors encountered in the Gluon portal.
