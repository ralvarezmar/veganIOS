### What's Changing?

We have released a new version **1.2.1** of **Santander Backend Component Template**.
This version includes the following change:

#### Backend Component Template Update

The following backend component template has been updated:

##### Santander Spring Boot Libraries

The new component template includes the latest versions of Santander Spring Boot framework:

* Santander Spring Boot framework version 1.2.1 (Spring boot 3.5.6)

### Why Is This Important?

Keeping the component templates updated prevents your applications from experiencing issues and vulnerabilities that have been resolved in the latest framework versions.

### How to Use This Feature?

#### Component Templates

All new components created will use the new component templates released. You can follow the [Backend Components](../../components/software/backend/index.md) documentation to create them.
