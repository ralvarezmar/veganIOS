### What is changing?

A new Technical Reference Architecture for Confluent Cloud on AWS has been published. This architecture provides standardized guidelines and best practices for interacting with Confluent Cloud platform deployed on AWS.

### Why is this important?

The publication of this reference architecture helps teams accelerate Confluent Cloud adoption, ensures compliance with Santander standards, and reduces risks associated with custom implementations.

It serves as a foundation for future Gluon capabilities.
