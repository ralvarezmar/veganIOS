## Gluon v1.2.0

20^th^ September 2023

![Static Badge](https://img.shields.io/badge/PLATFORM-Gluon_Portal-blue)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) API deployment components can now be created in your application much easier and faster from the API detail view  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Styles and accessibility aids have been improved  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Functionalities that are not available are correctly identified in the portal  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Some translations (EN/ES) on the portal have been improved according to localisation  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Company applications can now be accessed directly from the company detail view  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The application filters are now more precise and only show the business units belonging to the selected company  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The application's navigation breadcrumbs have been improved to provide a smoother experience  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Forms and search boxes have been improved with context-sensitive help for a homogeneous and intuitive experience  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) A confirmation or error message is now displayed for any action taken in Gluon for greater visibility of what is happening  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The content of the application owners section of the basic application information view can now be expanded and collapsed for a cleaner display  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The application team view is now instantly activated when two or more application owners register for the application. This ensures that application team members
can register once they have fulfilled the application registration requirements  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The application component view is now instantly enabled when you have GitHub provisioned in the Application Tools Workspace. This ensures that you can
create application components once they have met the application's registration requirements  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Update the Docs card links for all component templates to the correct ones.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) For better identification, the new spaces created in Confluence will be named after the name of the technical application registered in Gluon.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Onboarding problem solved for users with different corporalias and userid LDAP fields
