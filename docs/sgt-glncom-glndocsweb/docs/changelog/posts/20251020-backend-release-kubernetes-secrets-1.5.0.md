### What's Changing?

We have released a new version **0.1.1** of **kubernetes secrets**.
This version includes the following changes:

#### kubernetes secrets charts

We have released the following new version of Helm Chart:

* Secret helm chart version **v0.1.1**

### Why Is This Important?

Keeping the configmaps updated prevents your applications from experiencing issues.

### How to Use This Feature?

#### Component Templates

All new components created will use the new component templates released. You can follow the [Backend Components](../../components/software/backend/index.md) documentation to create them.

#### Deployment Helm Charts

The new deployment Helm Charts will be automatically used by every Arsenal, Darwin, and Santander Spring Boot deployment.
