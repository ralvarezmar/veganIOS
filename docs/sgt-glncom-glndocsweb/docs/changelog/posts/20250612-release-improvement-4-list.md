### What's Changing?

- ✅ **FIX: Support to new status from Service Now**  
  Any new status from Service Now now supported. No more strange behaviors when showing release lists where releases have statuses not registered into Gluon Release Module.

### Why Is This Important?

It is basic to be able to navigate through the releases page with no surprises by an unmaped detail from Service Now. Gluon Releases must support changes into Service Now and guarantee the experience to the developer that navigates into the releases page.
