We’re excited to announce the release of a new **iOS Base Application Component Template** in Gluon, designed to streamline the creation of iOS applications and provide a standardized, efficient starting point for iOS development across the Santander
Group.

### What's Changing?

The new iOS Base Application Component Template enables teams to quickly bootstrap iOS applications with:

- Complete project scaffolding following Santander Group’s quality and security standards.
- Integrated CI workflows for automated building, testing, and distribution to testing platforms.
- Built-in quality and security gates, ensuring compliance from the start.
- A structure that aligns with Gluon’s platform conventions, making it easier to maintain and scale projects.
- Immediate provisioning of essential resources such as GitHub repositories, SonarQube projects, and Fortify projects.

**Note:**
This initial release focuses on Continuous Integration (CI) workflows, including automated quality and security checks. Continuous Deployment (CD) workflows—such as automated production builds and App Store delivery—will be addressed in a future
update, based on ongoing demand from Santander Group entities.

This template is especially useful for development teams looking to accelerate their iOS app delivery while ensuring compliance with enterprise requirements.

### Why Is This Important?

This improvement reduces the effort required to set up new iOS applications, ensures consistency and reliability across teams, and empowers developers to focus on building features rather than configuring infrastructure. By adopting Gluon’s standards,
teams benefit from best practices and automated quality checks from day one.

### How to Use This Feature?

The new template is available directly within the Gluon platform. Teams can access it through the component catalog and start integrating it into their workflows immediately.

!!! note
    For detailed instructions on how to use the template, please refer to the documentation in the [iOS App Journey](../../components/software/front/mobile/ios/app.md) section.
