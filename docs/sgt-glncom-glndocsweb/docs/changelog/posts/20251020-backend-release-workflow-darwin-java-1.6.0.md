### What's Changing?

We have disabled Darwin Java components in PRO environment.
This version includes the following changes:

#### Darwin Microservices and libraries Component Template

The following backend component templates have been disabled:
     - Darwin Microservices
     - Darwin libraries

### Why Is This Important?

From now on, following the strategy of unifying the Arsenal and Darwin frameworks,
all developers will use the new Santander framework template component.

### How to Use This Feature?

#### Component Templates

All new components created will use the Santander framework component template. You can follow the [Backend Components](../../components/software/backend/index.md) documentation to create them.
