We've resolved an issue with the Releases list display that was causing temporary confusion for users.

### What was fixed?

- Eliminated the flicker effect where incorrect releases were momentarily displayed before showing the correct ones
- Improved the data loading process to ensure releases are correctly displayed from the first render
- Enhanced overall user experience by providing consistent and reliable release information

### Why is this important?

Users were experiencing confusion when visiting the Releases page, as they would briefly see incorrect release data before the page updated with the correct information.

With this fix, the Releases list now loads correctly on the first render, providing a more dependable and professional experience. Users can now confidently access and review release information without any momentary display of incorrect data.
