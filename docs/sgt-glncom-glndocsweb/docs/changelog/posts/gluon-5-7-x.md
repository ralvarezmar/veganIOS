## Gluon v5.7.0

November 5, 2024

### FEATURES

#### Application Management

![Fix](https://img.shields.io/badge/Fix-ea9999) &nbsp; Resolved issues referenced in ServiceNow tickets INC047890166 and INC047922484.  

#### Marketplace

![New](https://img.shields.io/badge/New-6fa8dc) You can now search for any information about the latest API definitions, including contract details, descriptions, and the BIAN catalog, using the Gluon Certified API Definition Knowledge.  
For more information, visit this [link](./../../components/software/api/framework/marketplace/api-copilot.md)  

### COMPONENTS

#### Front | Darwin

![Fix](https://img.shields.io/badge/Fix-ea9999) &nbsp; Resolved issues in Darwin SPA and Darwin Microfront to use puppeteer again as default engine to execute unit tests (for Darwin Classic flavor).  

#### Microservices | Arsenal

![Imp](https://img.shields.io/badge/Imp-93c47d) The **Arsenal Integration v4.14.2** versions are now available. This update fixes an issue related to Sonar for generated applications not using fields in tests.
