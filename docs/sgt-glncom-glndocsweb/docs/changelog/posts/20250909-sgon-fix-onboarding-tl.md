![Fix](../assets/images/fix-blog.png){ width=100% }

- Enabled the Technical Leaders group to manage secrets, aligning their permissions with those of the Developers group.

- Updated developer policies so that developers can now interact with secrets only at the application level, improving security controls.

### What's Changing?

- Added in onboarding process the management of technical lead group, assigning them the same policy of developers.

- Now, developers (and technical leads) can interact only with application secrets of certification paths.

### Why Is This Important?

- Fixed missing permissions for the Technical Leaders group to manage secrets.

- This correction strengthens security by ensuring that only authorized roles can manage secrets at the company level during certification processes, reducing the risk of unauthorized access.
