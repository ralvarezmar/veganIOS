### What's Changing?

Previously, company owners could only configure deployment windows for applications to which they had explicit permissions. Now, this role has permission to modify deployment window configurations for all applications in their company.

### Why Is This Important?

Deployment window configurations are only available to Gluon administrators and company owner roles.
 This change empowers company owners to create, edit, or delete deployment window configurations for all applications within their company, streamlining the management process.
