### What's Changing?

Arsenal Microservice 2.0, Arsenal Library, Darwin Java Microservice 2.0 and Darwin Java Library
component templates have been disabled in Gluon. They have been substituted by the Santander Spring Boot component templates,
which provide an improved development experience and better alignment with Santander Group standards.

### Why Is This Important?

Simplifying the component offerings in Gluon helps streamline the development process and ensures that teams are using the most
up-to-date and supported technologies.
By focusing on the Santander Spring Boot templates, we can provide better support, more consistent updates,
and a unified approach to backend development across the Santander Group.

### How to Use This Feature?

We encourage all teams to transition to the Santander Spring Boot component templates for their backend development needs.
You can also migrate your current Arsenal and Darwin Java projects to the Santander Spring Boot framework to take
advantage of the latest features and improvements.

You can follow the following migration guides:

- [Migrating from Arsenal Backend to Santander Spring Boot](../../components/software/backend/java/santander/framework/how-to-guides/arsenal-backend-to-santander-framework.md)
- [Migrating from Arsenal Integration to Santander Spring Boot](../../components/software/backend/java/santander/framework/how-to-guides/arsenal-integration-to-santander-framework.md)
- [Migrating from Darwin Java to Santander Spring Boot](../../components/software/backend/java/santander/framework/how-to-guides/darwin-spring-boot-to-santander-framework.md)
