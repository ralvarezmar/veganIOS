## Gluon v2.2.2

20^th^ December 2023

![Static Badge](https://img.shields.io/badge/CAPABILITIES-Back-red)  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) The use of a too long name in the API Legacy was breaking the workflow. This issue has been solved.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) The use of special characters in password when deploying a API Legacy Component was failing. This issue has been solved.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) When executing the workflow to make the DAST report it gives an error with error code 253. This issue has been solved.
