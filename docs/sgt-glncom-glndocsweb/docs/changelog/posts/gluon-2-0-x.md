![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The component templates catalog now provides the most up-to-date template version available.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The API version selector now includes scrolling and displays versions in descending order.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Modal forms now have a close button, preventing accidental closing when clicking outside the form.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Error pages now display consistently by keeping the portal header and footer visible.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The messages for onboarding/creation processes have been improved providing more accurate error information.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) The help-information displayed has been improved providing better context and a consistent layout.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Improved consistency of capitalization styles and formatting in text, tooltips, search boxes, lists, and navigation menu.  
![Static Badge](https://img.shields.io/badge/Improvement-93c47d) Animated loading icons have been added to inform users about onboarding/creation process in-progress.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Some action buttons have been fixed to only be active according to a specific user role in session.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) The user role information displayed in the Home page has been fixed.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Application list updates instantly upon new app registration, sorted by most recent registration date.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) The API catalog filters and pagination have been fixed.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Resolved issue causing modal form to close when attempting to close a toast notification.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Translations fixes for: page titles, use of anglicisms terms, date formats.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) The components list updates instantly upon new creation and is sorted by most recent registration date.
