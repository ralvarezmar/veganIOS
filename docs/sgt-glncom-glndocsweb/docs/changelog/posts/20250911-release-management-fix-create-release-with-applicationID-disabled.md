### What's Changing?

Even when Release Management is disabled for a company, it can now be enabled for specific applications. Previously, disabling Release Management at the company level automatically deactivated it for all applications.

### Why Is This Important?

This change allows users to register new releases for selected applications even when Release Management is disabled for the rest of the company's applications, providing more flexibility in release management administration.
