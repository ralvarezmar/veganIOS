### What's Changing?

- The following Infrastructure as Code (IaC) component templates will be removed from the Gluon portal and will no longer be accessible to users:
    - Object Storage
    - Virtual Machine (OHE Brazil)
    - Container Registry
    - Kubernetes Cluster
    - Encryption Manager
    - IAM Role
    - Network Load Balancer
    - Application Load Balancer
    - VPC Lite
    - Log Storage

### Why Is This Important?

These IaC component templates will remain unavailable until a comprehensive IaC strategy for the group is established.
