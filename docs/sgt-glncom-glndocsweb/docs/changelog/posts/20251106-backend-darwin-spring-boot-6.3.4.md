### What's Changing?

We have released a new version **6.3.4** of the **Darwin Spring Boot** framework.
This version includes the following [changes](../../components/software/backend/java/darwin/framework/current/CHANGELOG.md#634-changelog).

### Why Is This Important?

Each new version of the Darwin Spring Boot framework includes improvements and fixes that make microservice development easier,
as well as updates dependencies to avoid vulnerabilities.

### How to Use This Feature?

To use **Darwin Spring Boot**, you can consult the [technical documentation](../../components/software/backend/java/darwin/framework/current/index.md).

If you are using a previous version of the framework, you can upgrade to the new version by following the [Migration Guide](../../components/software/backend/java/darwin/framework/current/MIGRATION.md).
