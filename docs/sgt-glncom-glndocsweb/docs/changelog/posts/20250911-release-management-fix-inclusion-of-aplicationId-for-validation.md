### What's Changing?

With this change, users can only access releases that belong to their application. Previously, manually changing the release number in the URL allowed users to access release details outside their expected applications.

### Why Is This Important?

This fix ensures that users can only view information relevant to their applications, maintaining proper security boundaries and preventing unexpected access to release data.
