### What's Changing?

The API Deployment component, which was deprecated in August 2024, is being removed.

From now on, the only component available for deploying APIs is [**API Deployment 2.0**](../../components/software/api/apideployment/apis.md).

### Why Is This Important?

The workflows for components created with API Deployment will no longer be maintained or updated.

For APIs deployed with the API Deployment component, a new API Deployment 2.0 component must be created.
