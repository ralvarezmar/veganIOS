### What's Changing?

With this improvement, ansible deployment login supports special characters in passwords.

### Why Is This Important?

Sometimes passwords contain special characters, it is necessary that the automation supports these characters so that the user doesn't have to regenerate the password.

### How to Use This Feature?

To use this feature, a user doesn't need to change their current behavior.
