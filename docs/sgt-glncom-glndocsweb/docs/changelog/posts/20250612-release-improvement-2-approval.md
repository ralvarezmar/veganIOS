### What's Changing?

- 🔒 **Control of release approvers**  
  Now, when advancing critical release steps, only the App Owner, Product Owner, or authorized Change Management can approve.
   The system cross-checks ServiceNow and internal management data to prevent improper approvals, blocking the flow and displaying a clear error message when necessary.

### Why Is This Important?

A release process needs to be controlled by the right people. This improvement ensures this is really happening.
