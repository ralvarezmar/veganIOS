### What's Changing?

- An improvement has been implemented to allow the Company Owner users to update the configuration of the deployment window with "Enable all configuration" button.
When the "Enable all configuration" button is disabled, release creation, deployment and rollback actions are blocked.
The buttons for these actions are disabled and a message is displayed indicating that "Release Management has been blocked in your Application or Company".

### Why Is This Important?

- This change ensures that the release creation, deployment and rollback are blocked if necessary, minimizing risks.
