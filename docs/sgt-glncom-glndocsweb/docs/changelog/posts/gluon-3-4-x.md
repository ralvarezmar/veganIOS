## Gluon v3.4.0

April 24, 2024  

![Static Badge](https://img.shields.io/badge/PLATFORM-Gluon_Portal-blue)  
![Static Badge](https://img.shields.io/badge/Imp-93c47d) The forms have improvements to validations and displayed messages for a better experience.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Minor fix that updates the endpoint to the Terms Dictionary available in the API details
view floating bar options menu.  

![Static Badge](https://img.shields.io/badge/CAPABILITIES-Management-orange)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) During the application onboarding process, it is now possible to choose the Jira instance and Jira template to configure the project, and also choose one of the GitHub organizations
available in the company.  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) New functionality in order to facilitate the bulk uploading of applications into Gluon Platform.  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) The application components section now has a new search-filter by component template name.  
![Static Badge](https://img.shields.io/badge/Imp-93c47d) ZeroTouch. Updated views, validations and documentation  

![Static Badge](https://img.shields.io/badge/CAPABILITIES-APIs-green)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) Improved Subscription Process  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) Several usability improvements (Api detail and Catalog view, version change comparator)  

![Static Badge](https://img.shields.io/badge/CAPABILITIES-Back-blue)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) New Python Libraries Component (FW 3.2.3)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) New Darwin Java Component Version (FW 5.0.0)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) New Arsenal Java Component Version (FW 4.10.0)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) New Darwin Node Component Version (FW 4.0.0)  

![Static Badge](https://img.shields.io/badge/CAPABILITIES-Processes-6A1717)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) Appian: Possibility to connect to Cloud Appian Instances (through corporate proxy)  

![Static Badge](https://img.shields.io/badge/PLATFORM-Workflows_CI/CD-blue)  
![Static Badge](https://img.shields.io/badge/New-6fa8dc) New Gravity Components Gravity Sync Altair & Gravity Altair (Native). MVP  

![Static Badge](https://img.shields.io/badge/CAPABILITIES-Testing-127F16)  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Talos timeout on start: Adding a new command timeout to let the execution retrieve all dependencies on time.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) Fixed Scheduling Orchestration: Validation for field names and descriptions has been fixed, improving data integrity.  
![Static Badge](https://img.shields.io/badge/Fix-ea9999) HP Alm report expired: Remove HP Alm info when report is not available.
