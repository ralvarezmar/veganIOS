### What's Changing?

The Deployments Table in the Releases feature now displays both the **date and time** for planned releases, instead of showing only the date. This update affects the column that lists the planned release date for each deployment.

### Why Is This Important?

Displaying the exact time, in addition to the date, gives users more precise information about when a release is scheduled. This helps teams coordinate deployments and track release schedules more effectively.

### How to Use This Feature?

When viewing the Deployments Table, the Planned Date column will now show both the date and the scheduled time for each release, formatted according to your language settings.
