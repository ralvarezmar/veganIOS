### What's Changing?

Previously, when an error occurred while retrieving Octane/Laika evidence in the Testing task (Preproduction stage), the error was captured but not displayed to users. Now, these error details are properly shown when clicking the Refresh Release button.

### Why Is This Important?

This improvement allows users to understand the exact reason for errors in the Testing phase, helping them distinguish between actual system errors and configuration problems. This visibility enables faster troubleshooting and resolution.
