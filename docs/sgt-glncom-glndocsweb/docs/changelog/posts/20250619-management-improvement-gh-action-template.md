We're excited to announce a new **GitHub Actions Component Template** in Gluon, designed to simplify the creation of GitHub Actions and offer a standardized and efficient way across the Gluon platform.

### What's Changing?

The new GitHub Action Component Template simplifies the process of creating reusable actions for CI/CD pipelines. It includes:

- Enhanced compatibility with Gluon’s CI/CD ecosystem.
- As with any component created from Gluon, these components will be cataloged within their application.

This template is **especially useful for Teams responsible for developing local templates**, enabling them to focus on their specific requirements while leveraging a robust foundation.

### Why Is This Important?

This improvement reduces the effort required to set up GitHub Actions, ensuring consistency and reliability across projects. It empowers teams to adopt Gluon’s standards while maintaining flexibility for their unique needs.

### How to Use This Feature?

The new template is available directly within the Gluon platform. Teams can access it through the component catalog and start integrating it into their workflows immediately.

!!!Note
    For detailed instructions on how to use the template, please refer to the documentation available in the [Software Components](../../components/software/processes/github-action.md) section.
