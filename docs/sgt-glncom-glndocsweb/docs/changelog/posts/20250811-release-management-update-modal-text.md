### What's Changing?

The confirmation modal text in the company configuration screen has been update to replace the old "Zero Touch" references with "Gluon Release". This update applies to both **enable** and **disable** confirmation messages.

### Why Is This Important?

This change ensures that confirmation messages accurately reflect the current feature name, reducing confusion for users and maintaining consistency across the interface and tests.

### How to Use This Feature?

When enabling or disabling the Gluon Release feature for all application in a company, the modal will now display:

- **Enable:** Are you sure you want to disable Gluon Release for all applications from this company?
- **Disable:** Are you sure you want to enable Gluon Release for all applications from this company?
