### What's Changing?

- A new feature has been implemented to allow Release users to update the release date interval in the RM portal after extending it in Service Now.
This ensures that the release schedule in the RM portal reflects the updated values. Additionally, deployments are now restricted to occur only when the release dates fall within the defined deployment window.

### Why Is This Important?

- This change ensures that the release schedule remains accurate and aligned between Service Now and the RM portal, preventing issues caused by outdated schedules.
 By enforcing that deployments occur only within the deployment window, the process adheres to organizational policies and minimizes risks.
