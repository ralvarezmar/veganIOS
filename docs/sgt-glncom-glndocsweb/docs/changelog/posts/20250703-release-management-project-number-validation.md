### What's Changing?

- The **Project Number** is now validated to ensure it exists in the ITSM system. This enhancement improves data accuracy and ensures that only valid project numbers are used during the release creation process.

### Why Is This Important?

- Validating the Project Number in the ITSM system ensures that all releases are associated with legitimate and existing projects.
 This process helps maintain data integrity, prevents errors caused by invalid project references, and aligns release management with organizational standards.
  By enforcing this validation, teams can improve traceability, reduce operational risks, and ensure compliance with IT governance policies.
