### What's Changing?

Previously, only users with higher privileges (Admin or Application Owner) could perform the rollback action. Now, regular users (members) have permission to initiate rollbacks.

### Why Is This Important?

Allowing regular users to initiate rollbacks increases agility in incident response and troubleshooting by enabling faster rollbacks when necessary.
This change allows a wider range of users to maintain system stability and recover from deployment issues more efficiently.
