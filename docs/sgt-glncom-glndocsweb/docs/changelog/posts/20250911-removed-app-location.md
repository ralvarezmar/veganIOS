![Fix](../assets/images/fix-blog.png)

All references to the AppLocation parameter—which previously could have the values Intranet or Internet—have been removed from the Gluon Testing service. This parameter is now obsolete and no longer provides functional or technical value to the service.

### What's Changing?

No further references to AppLocation will be shown in Gluon Testing in any screen of information.

### Why Is This Important?

It prevents user confusion and simplifies the information being shown whilst tidying the internal code.
