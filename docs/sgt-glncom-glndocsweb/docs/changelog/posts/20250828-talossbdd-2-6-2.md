### What's Changing?

We are upgrading the TalosBDD version of the TalosBDD Component Template because there were credentials found in the previous version.
The version has been bumped from 2.5.1 to 2.6.2.

### Why Is This Important?

Due to the continuous security checks on the Github repositories, alerts were being raised on newly created TalosBDD components.
This upgrade solves this issue for all newly created TalosBDD components going forward.
