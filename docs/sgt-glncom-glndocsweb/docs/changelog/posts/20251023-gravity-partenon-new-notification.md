### What's New?

Gluon Gravity adds a new notification through SQAI TrX call in order to inform either Mainframe and Oracle tables that a given set of objects have taken part of a nexus release package. This call is performed either in MainframeRLSE execution
 (under Gobierno de Entornos approval) or MainframeCI executions (for localSW or maintenance efforts)

### Why is this important?

With these new call, Gravity registers objects/Version information needed for distinguish whether it has been sent to client (RE LX LINUX ORACLE entry) or already installed into client (OR or EX LX LINUX ORACLE entries)
