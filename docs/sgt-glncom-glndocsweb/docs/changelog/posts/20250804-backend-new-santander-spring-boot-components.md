### What's Changing?

We are excited to announce the addition of new microservices and libraries to the Santander Spring Boot Components.

These components are designed to replace Arsenal and Darwin Spring Boot components, providing just one framework to
build microservices with Spring Boot.

They include all the features and functionalities of the previous components.

### Why Is This Important?

The Santander Spring Boot Components provide a unified framework for building microservices with Spring Boot,
simplifying the development process and enhancing maintainability. By consolidating Arsenal and Darwin components into
a single library, we reduce complexity and improve the developer experience.

### How to Use This Feature?

To use the Santander Spring Boot Components, simply create new components using the Gluon application.
Also, you can consult [technical documentation](../../components/software/backend/java/santander/index.md).

!!!Note
     We are currently working on tools to enable automatic migration from Arsenal or Darwin components to the new
     Santander Spring Boot Components.
