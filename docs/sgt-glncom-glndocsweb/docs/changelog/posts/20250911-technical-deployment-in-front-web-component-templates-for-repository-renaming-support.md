### What's Changing?

A technical deployment has been carried out on the front web component templates to prepare all components for an upcoming release of workflows and the Gluon portal.

This future release will enable repository renaming. With this update, all front-end components are now ready so that changes in repository names will not impact current build, publish, or deployment processes.

### Why Is This Important?

This change ensures that front-end components remain robust and operational even as repository names evolve.
By decoupling the components from repository names, we will offer much more friendly names in the repository names.
