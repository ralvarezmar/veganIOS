### What's Changing?

There's no longer a need to add the Gluon service user in ITSM (*LDAP User name:* `user_tbr_gluon_rlse` / *name:* "Usuario RLSE Gluon Digital Services") to the group where the release will be created. This process has been simplified.

### Why Is This Important?

This simplifies the process of setting up a group to support Gluon Release Management.
