### What's Changing?

An enhancement has been implemented in the Banksphere component workflows so that changes to repository names will not affect CI/CD processes, releases, or deployments, for both existing and future workflows.  

### Why Is This Important?

This optimization ensures that all components remain fully operational when repository names are modified. By decoupling workflows from repository names, teams can use more user-friendly naming and maintain  
operational continuity without impacting automation or continuous delivery.
