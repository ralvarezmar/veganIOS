### What's Changing?

Progressive replacement of the copilot dashboard with a dashboard with more information, This dashboard will be populated with data from July/2025.

### Why Is This Important?

Since April GitHub change API to extract Copilot data, this new dashboard extract data with new extraction rules.

In addition. the dashboard will have information about:

- interaction with the copilot chat.
- Using the copilot as a reviewer of the pull-request
