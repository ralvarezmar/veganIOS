### What's Changing?

This improvement includes a new feature that will allow users to view information about API plans directly from the Gluon portal in the future.
It includes details about quota, rate limits and burst limits for each plan and technology, making it easier for users to visualize quickly how many requests can be made and how quickly.

This is the first step towards providing more comprehensive information about API plans.

### Why Is This Important?

By making API plan information and usage limits visible, we improve transparency and user experience. Users will be able to make informed decisions and manage their API usage more efficiently.
