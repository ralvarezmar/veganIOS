Today we are announcing that the Gluon Releases page has been moved to the Gluon Changelog section in Gluon Docs.

### What's changing?

- Posts are categorized allowing for easier navigation and filtering.

- Filtering by each category is available, making it easier to find specific types of updates.

- Each new feature, improvement, and fix is published in a separate post, providing additional context and details.

- Posts are archived by year.

### Why is this important?

Finding changes related to specific topics was complicated. Gluon releases aggregated changes in multiple categories making it difficult to find specific updates. Changes where listed but not explained and that made it hard to understand
the impact of each change, how to start using it, and how to benefit from it.
