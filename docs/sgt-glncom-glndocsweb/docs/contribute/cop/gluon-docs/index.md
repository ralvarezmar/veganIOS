**Welcome to Gluon Docs Community of Practice** and thank you for helping to improve Gluon Docs experience.

**Gluon Docs Community is the group of people behind Gluon Docs** growth in contents and quality: Writers, validators, platform engineers and proactive Gluon Docs readers.

**Do you want to join?** Send your proposals, questions... through [Gluon Docs Channel](https://github.com/santander-group-shared-assets/sgt-glncom-glndocsweb/discussions).
