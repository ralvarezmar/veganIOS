# Flame

Flame is Santander’s unified design platform that ensures efficiency and brand consistency in digital product design. ONE Platform, ONE documentation, ONE Santander.

## Flame Design System (FlameDS)

Flame design system is a set of standards to manage design at scale by reducing redundancy while creating a shared language and visual consistency across different application and channels.

This way, FlameDS helps us to create a better experience for our customers and employees.
You can learn more about Flame in the [Flame website](https://brand.santander.com/hub/93).

In Gluon we work side by side with Global Marketing to ensure that FlameDS is properly implemented in our products. We both also provide FlameDS (light and dark theme) as a reusable asset (css/scss, fonts and icons) for our developers.

- Learn how to use it in the [FlameDS documentation](https://brand.santander.com/document/591#/tokens-set-up).
- Take a look at the [FlameDS token engine source code](https://github.com/santander-group-shared-assets/santander-front-flame-ds)

## Flame User Interface (FlameUI)

FlameUI is a set of reusable components that are built on top of FlameDS. It is a Stencil component library wrapped as an Angular library that helps us to create consistent and accessible user interfaces.

This library will be provided from Gluon under the [following collaboration model](collaboration-model.md)

- Take a look at the [FlameUI source code](https://github.com/santander-group-shared-assets/santander-front-flame-ui)
