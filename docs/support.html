Soporte de VeganLens

VeganLens escanea códigos de barras y consulta bases de datos públicas para mostrar ingredientes, aditivos, alérgenos, información nutricional y un veredicto orientativo sobre la idoneidad de un producto para una alimentación vegana.

Cómo obtener ayuda

Para preguntas, comentarios o ayuda con la aplicación, escribe a r.alvarezmar@gmail.com.

También puedes informar de problemas o proponer mejoras en el gestor de incidencias de GitHub. No incluyas información personal innecesaria en una incidencia.

Preguntas frecuentes

¿Cómo escaneo un producto?

Concede permiso para usar la cámara y apunta al código de barras EAN o UPC. También puedes introducir el código manualmente. La aplicación consulta las bases de datos disponibles y muestra la información encontrada.

¿Qué significa «Sin datos suficientes»?

Significa que ninguna de las bases de datos consultadas aporta información vegana suficiente para mostrar un resultado. No significa que el producto sea vegano ni que no lo sea. Comprueba siempre el etiquetado oficial.

¿Qué significa el veredicto orientativo por ingredientes?

Cuando Open Food Facts no proporciona un análisis vegano, VeganLens puede revisar localmente la lista de ingredientes. Este resultado es orientativo: que no se detecten ingredientes de origen animal no confirma que el producto sea vegano. Revisa la etiqueta y las posibles trazas o certificaciones.

¿Cómo puedo aportar datos a Open Food Facts?

Desde la pantalla de contribución puedes rellenar los datos del producto, reconocer los ingredientes con OCR y añadir fotos, y después iniciar el envío de forma explícita. No necesitas iniciar sesión en la aplicación. Las contribuciones se envían a la base de datos que selecciones; no incluyas información personal en los textos ni en las fotografías.

¿Qué ocurre si no tengo conexión?

La aplicación conserva una caché local limitada de productos consultados y puede mostrar esos datos posteriormente sin conexión. Los productos que no estén en la caché no pueden consultarse hasta recuperar la conexión. Las contribuciones necesitan conexión para enviarse.

¿Qué idiomas admite?

La interfaz y las funciones de producto están disponibles en español, inglés, alemán, francés, italiano y portugués, según el idioma configurado en el dispositivo.

¿Qué opciones de accesibilidad incluye?

La aplicación incluye una paleta apta para personas con dificultades para distinguir colores, una fuente de alta legibilidad y tamaños de texto configurables. También proporciona etiquetas y textos de accesibilidad para las acciones y la información de la interfaz.

Privacidad

VeganLens no incluye analítica, publicidad ni rastreo. El análisis local de ingredientes y el reconocimiento OCR se realizan en el dispositivo. El historial, los favoritos y la caché se almacenan localmente.

Consulta la política de privacidad en español para conocer los datos locales, las consultas a bases de datos públicas y las contribuciones.
